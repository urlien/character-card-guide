# 角色人设标签格式

## 名称与占位符

- `char` 不使用占位符。先确定角色名称，并在正文中直接写真实名称，例如「禾安」。
- 玩家只使用 `{{user}}`，不要写死玩家姓名。
- 禁止继续使用 `$#char#$`、`$#user#$`、`{{char}}` 或「角色名」这类替代写法。
- 用户没有提供角色名时，根据设定补一个贴合世界观、可直接使用的名称；不要停在占位符状态。

## 标签规则

使用截图式的单行章节标签组织内容：

```text
<角色设定 名字：禾安>
<世界观>
这里写世界核心设定。
</世界观>
<基本信息>
- 年龄：24 岁
- 身份：种子铺守护人
</基本信息>

<与{{user}}的关系>
禾安与{{user}}从农场伙伴开始建立关系。
</与{{user}}的关系>
</角色设定>
```

标签只负责划分章节，遵循以下规则：

1. 开始标签和闭合标签都独占一行，使用全角或半角冒号均可；推荐全角冒号。
2. 每个开始标签必须有同名闭合标签，例如 `<世界观>…</世界观>`、`<道具>…</道具>`。
3. 角色主标签必须写成 `<角色设定 名字：真实角色名>`，并用 `</角色设定>` 闭合；闭合标签不重复名字属性。
4. 子章节写在所属外层标签内部，必须按后开先闭的顺序正确嵌套，不能交叉闭合。
5. 同一层级的标签名称保持稳定，不要一会儿叫「背景」、一会儿叫「往事」。
6. 原子信息用 `- 字段：内容`；氛围、关系与行为逻辑可用短段落。
7. 标签内容是自然语言设定，不放 HTML、CSS、脚本或 SDK 调用。

## 推荐顺序

完整新人设以 `<角色设定 名字：真实角色名>` 开始，以 `</角色设定>` 结束；世界观、基本信息、玩家关系、性格、说话方式、背景、能力边界与必要输出约定都在此根标签内。按需求选章节，不为达到固定数量而凑空段落。

世界书条目可使用 `<世界观>`、`<地点>` 等各自独立根标签，不要求每一条都有角色主标签。合并世界书到人设时，把 `<补充世界设定>…</补充世界设定>` 放在角色根标签的最终闭合之前，避免产生第二个根。

修改既有素材时保留语义和非本次范围的内容；格式修复不应偷偷增加人物关系、秘密或玩法规则。

不要改回 `【世界观】` 或 Markdown 标题。不要遗漏闭合标签，也不要写成 `<世界观>…</地图>` 这类名称不匹配的结构。

正则内容 -- 导入到角色卡的「正则」

看你的平台是哪种导入方式，二选一：
- 平台让你粘贴文本 -> 点下方「复制完整 JSON」，去平台正则处粘贴。
- 平台让你上传文件 -> 点「下载文件」得到 手机系统_正则.json 再上传。

开场白触发词 -- 必须加进角色卡「开场白」

不加这串、手机不会出现。社区动态读取不到？去「社区」检查正则匹配格式。

这是什么

一个可视化做「手机系统」的工具。你在左边配置手机外观、各个 App（商城、音乐、地图、档案、社区、背包），右边实时看效果，最后导出一份正则 JSON 导进你的角色卡，角色在聊天里就能打开一个完整手机界面。

几步走

  1. 通用：设置手机主题色、壁纸、悬浮按钮位置和文字、手机尺寸。
  2. 应用：启用/禁用各 App，调整图标和名称，添加自定义 App。
  3. 各 App 数据：商城商品、音乐歌单、地图地点、学生档案、社区/传闻正则、背包物品等。
  4. 外观：选主题预设或自定义配色。
  5. 导出：下载 JSON 导入角色卡「正则」，触发词加进「开场白」。

关键：社区和传闻怎么来

社区动态和传闻是从 AI 的回复消息里用正则抓取的。AI 按格式写 #社区动态# 名称\n[内容|...]\n#社区动态结束#，正则会把它替换成隐藏的标记 div，手机社区 App 再读取显示。在「社区」标签页可以修改正则。

购物车怎么运作

玩家在商城选商品加入购物车，点确认购买后，会往输入框写入购买清单文本，由 AI 处理扣款和发货。背包则从角色卡状态栏用正则读取物品数量。

保存与分享

编辑会自动存在本浏览器。备份配置 可下载一份配置 JSON 备份或分享给别人，对方 导入配置 即可继续编辑。

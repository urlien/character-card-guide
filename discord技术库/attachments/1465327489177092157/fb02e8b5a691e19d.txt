# 抓取式状态栏制作规范-柑硕

## 核心概念

**抓取式状态栏**：将数据与视图分离，AI只需输出精简的数据标签，前端JS自动解析并渲染到对应位置。

**优势**：
- 大幅减少token消耗（约70-80%）
- 支持数据继承（缺失数据自动从上条消息获取）
- 便于维护和扩展

---

## 转换步骤

### 第一步：分析原状态栏结构

将原状态栏拆分为：
1. **固定结构**（标签名、图标、布局）→ 写死在HTML
2. **动态数据**（数值、文字）→ 提取为数据属性

**示例 - 原状态栏**：
```
【生命值】78/100
【魔力值】45/60
【金钱】5000金币
【状态】中毒、虚弱
```

**拆分结果**：
- 固定：`【生命值】` `【魔力值】` 等标签
- 动态：`78/100` `45/60` `5000` `中毒、虚弱`

---

### 第二步：设计数据格式

#### 原则
1. **属性名精简**：用2-3字母缩写节省token
2. **分隔符统一**：
   - 名称与值用 `:`
   - 当前/最大用 `/`
   - 多项用 `,`
   - 子项用 `|`
3. **语义清晰**：缩写要有规律可循

#### 常用缩写对照表

| 类型 | 原名 | 缩写 |
|-----|------|------|
| 环境 | time/location/present | tm/loc/pr |
| 角色 | name/title/job | nm/tt/jb |
| 数值 | money/rank | mn/rk |
| 状态 | state/buff | st/bf |
| 资源 | 资源条统一用zy | zy="hp:78/100,mp:45/60" |
| 列表 | ability/item/skill | ab/bag/sk |

#### 列表类数据格式

```
简单列表：ab="能力1,能力2,能力3"
键值列表：bag="物品名|数量,物品2|数量2"
多值列表：sk="技能名|消耗|描述,技能2|消耗2|描述2"
```

### 第三步：设计HTML模板

#### 数据插槽标记

用 `data-f="字段名"` 标记需要填充数据的位置：

```html
<!-- 单值插槽 -->
<span data-f="nm">--</span>
<span data-f="mn">--</span>

<!-- 列表插槽 -->
<div data-list="bag"></div>
<div data-list="npcs"></div>
```

#### 模板示例

```html
<div class="status-bar">
  <!-- 固定结构 -->
  <div class="section">
    <span class="label">姓名</span>
    <span class="value" data-f="nm">--</span>
  </div>
  <div class="section">
    <span class="label">金钱</span>
    <span class="value" data-f="mn">--</span>
  </div>
  
  <!-- 列表区域 -->
  <div class="item-list" data-list="bag"></div>
  
  <!-- 数据区（隐藏） -->
  <div class="z-data" style="display:none">
    <div data-st nm="张三" mn="5000"></div>
  </div>
</div>
```

### 第四步：编写解析函数

#### 基础框架

```javascript
window.parseStatus = function(box) {
  // 1. 工具函数
  var q = function(s) { return box.querySelector(s) };
  var attr = function(el, a) { return el ? el.getAttribute(a) : null };
  var setTxt = function(sel, val) {
    var el = q(sel);
    if (el) el.textContent = val || '--';
  };
  
  // 2. 获取数据（支持继承）
  var findData = function(dataAttr, currentOnly) {
    // 先找当前box
    var data = box.querySelector('.z-data');
    if (data) {
      var found = data.querySelector('div[' + dataAttr + ']');
      if (found) return found;
    }
    // 不继承则返回null
    if (currentOnly) return null;
    // 向上查找之前的状态栏
    var allBoxes = document.querySelectorAll('.status-bar');
    var idx = Array.from(allBoxes).indexOf(box);
    for (var i = idx - 1; i >= 0; i--) {
      var prevData = allBoxes[i].querySelector('.z-data');
      if (prevData) {
        var found = prevData.querySelector('div[' + dataAttr + ']');
        if (found) return found;
      }
    }
    return null;
  };
  
  // 3. 解析并填充
  var st = findData('data-st', false);
  if (st) {
    setTxt('[data-f="nm"]', attr(st, 'nm'));
    setTxt('[data-f="mn"]', attr(st, 'mn'));
    // ... 其他字段
  }
};
```

#### 资源条解析函数

```javascript
var parseZy = function(str) {
  if (!str) return [];
  var result = [];
  var items = str.split(',');
  for (var i = 0; i < items.length; i++) {
    var match = items[i].trim().match(/^([^:]+):(-?\d+)\/(\d+)/);
    if (match) {
      result.push({
        name: match[1].trim(),
        cur: parseInt(match[2]),
        max: parseInt(match[3])
      });
    }
  }
  return result;
};

// 使用：zy="hp:78/100,mp:45/60"
var zyData = parseZy(attr(st, 'zy'));
// 结果：[{name:'hp',cur:78,max:100}, {name:'mp',cur:45,max:60}]
```

#### 键值列表解析函数

```javascript
var parseKv = function(str) {
  if (!str) return [];
  var result = [];
  var items = str.split(',');
  for (var i = 0; i < items.length; i++) {
    var parts = items[i].trim().split('|');
    if (parts.length >= 2) {
      var obj = { name: parts[0].trim(), val: parts[1].trim() };
      if (parts.length >= 3) obj.extra = parts[2].trim();
      result.push(obj);
    }
  }
  return result;
};

// 使用：bag="剑|1,盾|1,药水|5"
var bagData = parseKv(attr(st, 'bag'));
// 结果：[{name:'剑',val:'1'}, {name:'盾',val:'1'}, {name:'药水',val:'5'}]
```

### 第五步：触发解析

#### 方法一：onerror触发（推荐）

```html
<!-- 放在状态栏末尾 -->
<img src="x" style="display:none" onerror="
  (function(img){
    var box = img.closest('.status-bar');
    if (box && typeof window.parseStatus === 'function') {
      window.parseStatus(box);
    }
    img.remove();
  })(this)
">
```

#### 方法二：onload触发

```html
<img src="data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7" 
     style="display:none" 
     onload="window.parseStatus(this.closest('.status-bar'));this.remove()">
```

## 数据继承机制

### 继承规则设计

| 数据类型 | 是否继承 | 说明 |
|---------|---------|------|
| 环境信息 | ✅ 继承 | 时间地点等不常变 |
| 角色属性 | ✅ 继承 | 姓名职业等基本不变 |
| 资源数值 | ✅ 继承 | 但通常每次都更新 |
| 选项列表 | ❌ 不继承 | 每次都不同 |

### 代码实现

```javascript
// currentOnly=true 表示不继承
var env = findData('data-env', false);  // 继承
var st = findData('data-st', false);    // 继承
var opt = findData('data-opt', true);   // 不继承
```

### 使用示例

```html
<!-- 第1条消息：完整数据 -->
<div data-env tm="12:00" loc="王城"></div>
<div data-st nm="勇者" mn="1000" zy="hp:100/100"></div>

<!-- 第2条消息：只更新变化的 -->
<div data-st zy="hp:80/100" mn="1200"></div>
<!-- env继承上条，nm继承上条 -->
```

【在场】茜、真红
━━━━━━━━━━━━━━━━━━━━
【姓名】柑硕
【职业】调查员
【金钱】5000府币
【生命】120/220
【星能】80/100

## 注意事项

1. **括号内容过滤**：如需忽略说明文字，添加清理函数
   ```javascript
   var clean = function(str) {
     return str.replace(/[（(][^)）]*[)）]/g, '').trim();
   };
   // "hp:78/100（受伤）" → "hp:78/100"
   ```

2. **特殊字符转义**：数据中避免使用 `|` `,` `:` `/`，或用其他分隔符

3. **函数定义位置**：主函数定义在第一个状态栏中，后续复用
   ```html
   <!-- 首个状态栏 -->
   <div class="fn-define" style="display:none">
     window.parseStatus = function(box) { ... }
   </div>
   ```

4. **颜色自动分配**：资源条等可按索引循环取色
   ```javascript
   var COLORS = ['#4ade80','#60a5fa','#f59e0b','#a78bfa'];
   var color = COLORS[index % COLORS.length];
   ```

5. **列表动态渲染**：清空后重建，避免残留
   ```javascript
   var listBox = q('[data-list="bag"]');
   if (listBox) {
     listBox.innerHTML = ''; // 先清空
     // 再添加新元素
   }
   ```

## 检查清单

转换完成后确认：

- [ ] 数据区有 `style="display:none"`
- [ ] 所有动态内容都有 `data-f` 或 `data-list` 标记
- [ ] 固定文字（标签名、图标）写死在HTML
- [ ] 解析函数包含继承逻辑
- [ ] 触发器放在模板末尾
- [ ] 测试：首条完整数据正确显示
- [ ] 测试：后续省略数据正确继承

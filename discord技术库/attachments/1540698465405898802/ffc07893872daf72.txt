分区与标签使用规范
版本号：v3.1　生效日期：2026年9月10日　最近修订：2026年9月10日

第一章　总则

1.1　适用范围
本规范适用于在魅魔网站平台公开发布的全部角色卡，内容涵盖角色卡投递时的分区选择与自定义标签使用的相关要求。

1.2　术语定义
- 分区：平台预设的内容分类项，显示于角色卡详情页及平台筛选栏。创作者投递时可为每张角色卡选择一个或多个分区，角色卡将同时出现在所有对应分区的筛选结果中。
- 自定义标签：创作者自行添加的内容标记（如 #纯爱、#日常 等），用于补充描述作品特征。
- 分区类别：平台将全部分区按内容属性归纳为五大类别，分别为世界观类、内容形式类、角色类型类、关系结构类、尺度 / 倾向类（详见第二章至第六章）。
- 敏感分区：指内容属性与相当规模玩家的强规避偏好直接冲突、漏标或错标可能对玩家体验造成显著损害的分区，共六个：媚黑、NTR、类NTR、重口味、R18G、人兽；除此之外均为普通分区。敏感分区适用第 5.3 条强制标注要求及第 1.6 条优先级规则；其中 NTR、类NTR 另适用第 5.21 条。

1.3　制定目的
为提升作品分类准确性、维护平台内容展示秩序、保障玩家浏览体验，平台制定本规范，并明确对应的合规要求与处理机制。

1.4　基本原则
- 创作者为每张角色卡所选择的全部分区，均须真实反映该作品的核心设定、情节走向或主题属性，不得以扩大曝光为目的作不符实际的标注。
- 自定义标签应作为分区的补充说明，不得与所选分区相互矛盾，亦不得借此规避应当标注的敏感分区。

1.5　多分区组合规则
不同类别的分区可同时选择，例如"修仙 + 女频 + R18G"；同一类别内可选多个，但建议聚焦最核心的特征，避免无效叠加。

1.6　敏感分区优先级
若作品涉及多个敏感分区，应按以下优先级判断其核心敏感属性及展示归属：
媚黑 ＝ NTR & 类NTR ＞ 重口味 & R18G & 人兽 ＞ 其他普通分区
该优先级用于确保作品按其最核心、影响范围最广的内容属性归类，避免误分类或引发争议。

1.7　违规处理
审核组有权对存在以下情形的角色卡采取调整分区、驳回投递、设为私密或依规处罚等处理：
- 分区滥用、明显不符或具有误导性；
- 敏感分区错标、漏标；
- 自定义标签与所选分区明显矛盾，或借此形成误导性展示；
- 经审核组依据设定内容及玩家反馈认定分区不符的。
因作者分区选择或标签使用不当造成的流量、收益电量或其他损失，由作者自行承担。具体处理标准参照《角色卡违规处理与处罚细则》第 2.4 条（分区标注不符）、第 2.5 条（虚假包装 / 误导性投递）执行。

第二章　世界观类分区（决定故事舞台）

2.1　分区说明
世界观类分区用于标识作品的世界设定与文化背景。同一作品涉及多个世界观元素时，按以下优先级选择主分区：
— 修仙 ＞ 武侠 ＞ 西幻 ＞ 玄幻&科幻 ＞ 古风
判断依据为体系的封闭程度与专属性：体系越封闭、专属术语越鲜明，优先级越高；兜底性越强、包容范围越宽，优先级越低。修仙拥有灵根、渡劫、飞升等高度专属的术语体系，优先级最高；武侠以东方武学江湖为核心，体系明确；西幻有中世纪、魔法、骑士等具体的西方文化参照；玄幻&科幻包容范围最宽，作为非修仙 / 武侠 / 西幻的架空世界观作品的归属项；古风仅作背景板使用，兜底性最强，优先级最低。

2.2　分区定义
— 古风：以古代中式 / 东方文化为主要背景设定，包含朝代、宗法、宫廷、民俗、江湖等元素。可包含少量神怪、灵异元素，但超自然力量体系构成核心驱动机制的，应优先选择修仙、武侠或玄幻&科幻分区，不得以古风兜底。
— 武侠：以江湖恩仇、门派纷争、侠义精神为主轴的东方武学世界观，强调内功、轻功、招式等武学体系。
— 修仙：以修炼、长生、飞升为核心的东方幻想世界，常见灵根、功法、门派、渡劫等体系。
— 西幻：西方幻想背景设定，包含魔法、宗教、骑士、精灵、中世纪王国等经典元素。
— 玄幻&科幻：架空世界观结合超自然或超现实力量体系。玄幻侧重超自然设定，常见异能、异世界、多文明融合、神魔体系；科幻侧重科学逻辑与未来设定，常见星际、废土、赛博、机械改造等。
— 校园：以学校环境为主要舞台，包含师生、同学、社团等校园关系结构。

第三章　内容形式类分区（决定创作结构）

3.1　分区说明
内容形式类分区用于标识作品的叙事方式、互动结构或功能定位。

3.2　分区定义
— 角色扮演：以玩家代入特定身份（如老师、学生、雇员、王族、奴隶、伴侣等）为核心，强调身份扮演带来的代入感与互动张力。本分区亦为通用兜底分区：作品无明显侧重或难以归入其他分区的，可选择此区。
— 剧情：以情节推进与角色互动为核心，类似 galgame 的渐进式展开。作品须具备作者明确预设的剧情主线或事件链，而非完全依赖玩家自由发挥，常见要素包括分支选择、阶段变化、任务目标、多结局等。
— 世界模拟器：以整体世界结构与规则系统为核心，强调世界规则、主要关系方、势力 / 群体结构、环境逻辑与事件运行机制。AI 在既定框架下动态生成角色、事件与互动，重点不在单一角色或固定剧情塑造，而在世界如何基于自身规则持续运转、扩展与演化。常见特征包括题材相关事件的持续发生、关键角色或 NPC 的动态介入、不同组织 / 群体 / 关系方之间的互动，以及玩家选择对世界状态的后续影响。
— 玩法模拟器：以玩家扮演特定角色，体验某种工作、生活方式、关系结构、身份处境或活动流程为核心。不要求完整大世界或复杂多势力结构，但需围绕特定玩法建立持续互动机制，重点在于玩家的选择会被关键角色 / 关系方记住，并影响后续事件、关系与处境。
— 模拟经营：以经营、管理、资源调配为核心机制，包括但不限于商铺、王国、农场、组织、人际关系等的长期运营，强调数值变化、决策权衡与累积成长。
— 系统：主角获得"系统"绑定（常表现为脑内提示音、任务面板、签到界面等），通过完成系统发布的任务获取奖励、提升能力或推进剧情。常见等级、积分、签到、任务链、强制任务等机制。
— 游戏：以模拟特定游戏类型为核心结构，如生存挑战、密室逃脱、TRPG 跑团、剧本杀、桌游等。强调玩家作为"参与者"完成游戏目标，具有明确的胜负条件或通关结构。
— 悬疑：围绕谜团展开剧情，强调线索收集、推理逻辑、信息隐藏与真相揭示。
— 唯美：注重氛围、情绪与意境的表达，画面感与情绪体验重于互动结果。常见诗意叙述、慢节奏推进、细腻心理描写、感官化场景渲染等手法，整体偏向温和、浪漫的情感陪伴型内容，不强调刺激或强剧情冲突。
— 救赎：围绕角色的堕落、创伤、黑暗经历展开，强调通过陪伴、理解与互动逐步修复其心理状态、重建情感连接的过程。可以是玩家治愈角色，也可以是角色之间的相互救赎。
— 同人：基于现有动漫、游戏、影视等 IP 的二次创作角色或世界观。
— 抽象：风格跳脱、戏谑、不正经的内容，常见网络抽象文化、烂梗叠加、无厘头叙事、对常规设定的恶搞或颠覆。整体追求"乐"和"癫"的氛围，不以正经设定或代入感为目标。
— 工具：纯功能性辅助工具卡，如文风模仿、文笔润色、翻译辅助、文本扩写、格式整理等，不涉及角色、世界观或剧情设定的生成、辅助或扩写。
注
- 任何具备生成 / 辅助 / 扩写角色、世界观或剧情设定功能的工具卡，均不得以公开投递形式发布至任何分区。
- 归入世界模拟器或玩法模拟器的角色卡，除符合上述分区定义外，还须满足平台对模拟器类作品的有效内容锚点要求，具体见《模拟器类角色卡过审调整及分区细化说明》。作品同时具备完整世界生态与明确玩法体验的，可同时选择两个分区；仅符合其中一种的，应选择更贴合作品核心体验的分区。

第四章　角色类型类分区（决定主要角色特征）

4.1　分区说明
角色类型类分区用于标识作品主要角色的外形、年龄段、气质或种族特征。

4.2　分区定义
— 萝莉：以幼态、年龄感偏小的女性角色为核心设定，强调外形、气质或行为上的稚嫩属性。
— 正太：以幼态、年龄感偏小的男性角色为核心设定，强调外形、气质或行为上的少年感与青涩属性。
— 御姐：外貌、身材、个性及气质强势、独立，具明显主导气场，在互动关系中通常处于引导或上位位置，给人大姐姐感觉的女性角色。
— 熟女：年龄层、社会角色或人生阶段已明显成熟的女性角色，常带有母性、人妻或现实生活取向，强调年龄感、经验感与照顾属性。
— 男娘：男性角色具有明显女性化的外貌、气质或装扮，常以"反差"或"伪娘"为核心吸引点。
— 假小子：外表或行为风格偏男性化的女性角色。
— 性转：角色经历性别转变（如男变女、女变男）或以性别转换为核心设定要素的作品，常见变身、灵魂互换、性别交换等情节结构。
— 扶她：女性角色拥有男性性器官的设定。
— 福瑞：以拟人化动物角色为核心，源自欧美 furry 文化语境，强调毛皮、兽耳尾、爪、口鼻等动物特征与人格化的结合，审美核心在于"动物拟人"本身的吸引力。
— 兽人：以奇幻种族中的非人形角色为核心，常见兽人、龙人、哥布林、半兽人、异形种族等，多见于西幻、玄幻&科幻语境，强调种族设定与世界观结合。
— 人兽：涉及人与动物形态生命之间的越界关系设定。

第五章　关系结构类分区（决定情感 / 性向走向）

5.1　分区说明
关系结构类分区用于标识作品的情感关系结构与互动模式。

5.2　分区定义
— 恋爱&攻略：主角与角色之间存在明确的情感推进与互动机制，强调关系发展、角色转化与好感演变。
— 后宫：主角同时与多个情感或性关系对象建立联系，强调"一对多"的关系结构。可以是和谐共处的后宫氛围，也可以是充满张力的修罗场氛围。
— 百合：以女性角色之间的情感、爱恋或亲密关系为核心的设定。
— 女生视角：以女性角色为第一人称或主要视角推进剧情，强调女性体验、情绪变化与沉浸感。
— 女频：以女性受众为主要导向，强调情感代入与关系张力。BL、4i及以男男情感关系为核心的双男主等典型女性向关系模式，作为主要互动内容之一的，应归入女频；BG、ABO、NP、虐恋、强制爱、年下、骨科等则结合整体创作取向综合判断。
— 伦理：涉及家庭、亲属、师生、上下级等存在明显道德争议或伦理禁忌的关系设定。
— 母系：角色对主角构成"母"的身份定位，包括血缘母亲、继母、养母，以及无血缘但以母子 / 母女身份互动的角色设定。核心为母角色身份带来的依赖、照顾或独占等关系张力，并构成作品的主要角色关系或核心互动方向之一，与角色外形、年龄特征无关。
— NTR：主角与角色之间已存在相互确认或明显双向指向的恋爱、暧昧、伴侣、婚约、婚姻或准恋爱关系。第三者已经实际介入该关系，并对原有的情感、亲密或伴侣位置造成侵入、削弱或取代；或第三者虽尚未实际介入，但已对目标角色形成明确的恋爱、性、占有或关系竞争指向，并符合第 5.21 条“潜在介入型”的成立条件。主角处于“被夺走者”或存在明确关系侵入风险的位置。本分区以主角在关系中所处的位置为成立要件；主角表现为麻木、默许、自我说服、快感转化或其他非典型情绪反应的，不影响判断。
— 类NTR：主角与角色之间不存在明确的双向恋爱 / 暧昧关系，或仅存在单相思、亲情、依恋、陪伴、守护等非恋爱关系，但双方已形成明显的情感独占关系，即存在唯一性、依赖性、归属感、排他性期待或其他明确的情感绑定。第三者已经实际介入，并使该关系受到侵入、削弱或取代；或第三者虽尚未实际介入，但已对目标角色形成明确的恋爱、性、占有或关系竞争指向，并符合第 5.21 条“潜在介入型”的成立条件。主角处于“被夺走者”或存在明确关系侵入风险的位置；情绪反应形式同 NTR，不构成成立要件。
— NTL：主角处于"夺走者 / 介入者"位置，主动或被动介入他人已经存在的恋爱、暧昧、亲密或情感独占关系，并推动目标角色的情感、亲密或关系重心向主角发生偏移，俗称"你牛别人"。

5.21　NTR / 类NTR / NTL 的判断与标注细则
本条为 NTR / 类NTR / NTL 三个分区的判断与标注规则；第 5.3 条的通用标注要求涉及该三个分区的，另按本条判断。
本条“位置判断”“NTR 与类NTR 的区分”“前史与既往经历”中涉及实际介入的内容，以第三者已经介入为前提；第三者尚未实际介入但存在明确关系指向的，按“潜在介入型的判断”处理。

— 位置判断 —
以主角在关系中的位置为准：主角作为原关系方，第三者介入并使其原有关系或情感独占性受到侵入、削弱或取代的，按 NTR / 类NTR 判断；主角作为第三者介入他人既有关系，并推动目标角色向自身发生关系偏移的，按 NTL 判断。主角在同一作品中同时处于上述两种位置的，应同时标注对应分区。

— NTR 与类NTR 的区分 —
无论第三者已经实际介入，还是仅达到潜在介入程度，均以主角与目标角色之间原有关系的性质进行区分：
— 已存在相互确认或明显双向指向的恋爱、暧昧、伴侣、婚约、婚姻或准恋爱关系的，按 NTR 判断；
— 不存在上述恋爱关系，但存在亲情、依恋、陪伴、守护、单相思等明显情感独占关系的，按 类NTR 判断。

— 潜在介入型的判断 —
第三者尚未实际介入时，须同时符合以下三项：
— 目标角色与主角之间存在恋爱、亲密关系，或存在明显的情感独占关系；
— 设定明确写明第三者对目标角色存在恋爱、性、占有或关系竞争层面的指向；
— 第三者构成作品的主要角色、固定互动角色、可攻略对象或主要关系方之一，并具备实际出场与互动。
本情形以当前设定中的关系指向为判断依据，不以第三者已经采取实际介入行为为成立要件；设定中写明第三者不会采取行动的，不影响成立。
仅有审美欣赏、普通好感、泛化性吸引，或第三者仅为背景性、一次性、无实际互动角色的，不构成本情形。
符合本情形的，按照主角与目标角色原有关系性质进行分类：存在恋爱、暧昧、伴侣、婚约、婚姻或准恋爱关系的，标注 NTR；仅存在亲情、依恋、陪伴、守护、单相思等明显情感独占关系的，标注类NTR。

— 主角自主同意的排除 —
第三者的介入经主角自主同意的，在同时满足以下两项时，不按 NTR / 类NTR 判断；任一项不满足的，仍按 NTR / 类NTR 判断：
— 自主同意：主角在第三者介入前明确知情，并基于自主意愿明确同意或主动促成、安排、推动该介入。被迫、被欺瞒、被施压、既成事实后接受或无力阻止的，不满足本项；在催眠、精神控制、药物、长期操控或类似手段影响下作出的同意，不视为自主意愿。
— 体验重心：作品的主要内容与玩法重点不以主角原有关系受到侵占、削弱或夺取为核心体验。
潜在介入型情形，主角对第三者的关系指向明确知情并自主同意，且同时满足上述两项的，不按 NTR / 类NTR 认定。

— 关系范围 —
NTR / 类NTR 相关内容仅涉及与主角不存在情感独占、亲密或伴侣关系的角色的，不适用第 5.3 条的标注要求。

— 前史与既往经历 —
NTR / 类NTR 相关内容以前史、既往经历、回忆或背景交代形式存在的，符合下列任一情形，即须标注对应分区：
— 承担该内容的角色、势力或关系方仍存在于当前设定中；
— 当前时间线已设置该情节再次发生、延续、重演或被玩家介入的前置条件、触发线索或事件设计。

5.3　敏感分区强制标注要求
— 标注义务 —
作品设定中存在敏感分区相关属性或元素的，必须添加对应分区（范围见第 1.2 条）；多项同时存在的，应同时标注，不得遗漏。NTR / 类NTR 另适用第 5.21 条。

— 标注阈值 —
敏感分区的标注阈值低于普通分区。普通分区依《角色卡违规处理与处罚细则》第 2.4 条以作品核心内容为判断依据；敏感分区不要求相关元素构成作品主体或主要内容，符合下列任一情形的，即须标注：
— 相关内容在有效设定内容中具备可识别的分量；
— 相关内容构成作品的可达体验路径之一。
本条以相关内容在作品中的实际存在与呈现为准，与该内容涉及的角色是否与主角存在关系无关。

— 判断依据 —
前款所称分量与可达性，以角色设定、世界书及其他有效设定内容中的实际分布为准，不以玩家在常规游玩中是否必然遭遇为据。将相关内容置于低触发概率条目、深层分支或需特定操作方可进入的路径的，不影响本条适用。

— 不强制标注的情形 —
相关内容仅在世界观通则、群体性现象或时代背景的概括性叙述中简要提及，未指向具体角色，未构成作品的题材属性或氛围基调，且作品中未设置以该内容为行为动机、目标或核心定位的角色、势力或关系方的，不强制标注。

— 处理 —
审核组亦有权依据设定内容及玩家反馈，对作品进行私密并要求作者补充分区。对社区秩序或平台内容生态造成明显负面影响（认定标准见《角色卡违规处理与处罚细则》第 1.3 条）的，按该细则第 2.4 条档 C 处理。

第六章　尺度 / 倾向类分区（决定内容强度或特定癖好）

6.1　分区说明
尺度 / 倾向类分区用于标识作品的内容尺度、特定癖好取向或张力来源。本类分区可与上述各类分区并存，是对作品具体内容属性的补充标记。

6.2　分区定义
— SFW：Safe for Work，适合公共场合浏览的内容，设定与互动中不包含任何性暗示或瑟瑟要素。
— 情欲肉爱：以性行为本身为绝对核心且单刀直入，强调肉体快感、欲望释放与场景构建，情节以直接刺激为主导。
— 重口味：尺度边缘、涉及小众或极端癖好取向的内容，包括但不限于特殊体液、SM 重度、特殊体型偏好、极端羞辱等设定。
— R18G：以血腥、暴力、猎奇、心理冲击为核心要素的限制级设定（"G"代表 Gore），常见伤害、肢解、死亡描写、极端心理压迫等内容。
— 调教&强迫：包含支配、控制、命令等非平等互动关系，以压制与服从为主要结构。其中"调教"侧重长期、过程性的训练与塑造（如 SM、宠物 play、奴隶训练等），"强迫"侧重强制性行为或情境。核心是权力差与强制性。
— 顺从：角色性格偏被动、听话、单纯，易接受引导或命令，核心是角色性格本身的被动属性，适合主导—服从关系的互动结构。
— 羞辱：角色在言语或行为上被贬低、侮辱、公开羞耻，核心是屈辱过程与心理反馈。
— 催眠：洗脑、精神控制、记忆篡改、时停等设定，强调角色意识被操控、行为因外力发生改变的过程与结果。
— 媚黑：以黑人男性角色为主要性吸引点或审美核心的角色与剧情设定，内容围绕该角色类型展开，在设定或互动中占据核心地位。本分区为平台最高优先级敏感分区，仅在作品确实以此为核心要素时使用，严禁与实际内容不符的滥标或漏标。
— 露出：在公共或半公开场合暴露身体或发生性行为，强调羞耻与刺激感。
— 隐奸：在他人不知情的前提下进行性行为，强调隐蔽性与紧张感。
— 恋足：以足部相关情节、互动或审美偏好为核心要素的设定。
— 反差：以角色在身份、性格或行为层面的强烈反差作为核心吸引点和叙事张力来源的设定，反差本身即为卖点。常见类型包括：外表清纯实则放浪、平日冷淡仅对玩家温柔、强势独立却私下依赖、人前端庄人后失控等。

第七章　附则

7.1　规则解释
本规范由平台制定，具体执行与适用说明由审核组负责。对于存在争议或规则边界不明的情形，平台保留进一步说明及调整适用口径的权利。

7.2　修订与公示
本规范的修订由平台发起，修订后将在官方渠道公示，自公示之日起立即生效，修订前已生效的处理结果不受影响。

7.3　参照执行
本规范中涉及的违规处理方式及处罚机制，参照《角色卡违规处理与处罚细则》第 2.4 条、第 2.5 条及其他对应条款执行。

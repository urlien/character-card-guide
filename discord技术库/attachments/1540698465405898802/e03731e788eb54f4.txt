角色卡违规处理与处罚细则
版本号：v3.3　生效日期：2026年8月24日　最近修订：2026年8月24日

第一章　总则

1.1　适用范围
本细则适用于在魅魔网站平台任意站点 / 页面公开发布、可被用户访问与传播的角色卡。处理范围涵盖角色卡全部内容，包括但不限于标题、简介、第一句话、设定、封面、分区、标签及其关联素材、美化内容等。

1.2　制定目的
为维护社区创作生态、作品曝光分发的公平性与内容呈现的规范性，平台对各类破坏原创秩序、扰乱发布秩序、影响社区公平、违反内容合规要求或损害用户体验的违规行为进行规范处理，以保障创作者合法权益，减少违规行为对用户认知、游玩体验、社区环境及平台运营造成的混淆、误导与不良影响。
本细则同时致力于建立可预期、可依据的处理标准，确保处理结论均建立在客观事实与规则依据之上，使创作者与用户能够合理预判平台处理方式。在兼顾已游玩用户体验连续性的前提下，平台鼓励作者通过合规创作与有效迭代持续提升作品质量，并通过稳定、一致的规则执行保护所有创作者的长期利益。

1.3　术语定义
本细则中以下术语的含义如下：
— 当事方 —
- 平台：指魅魔网站及其运营管理主体，为本细则的制定与适用主体。
- 审核组：指平台授权负责本细则具体执行、举报核实、申诉受理及相关适用说明的工作团队。
— 内容范围 —
- 有效设定：指角色卡中由作者自行创作、构成作品实质体验的核心内容，包括但不限于世界观框架、角色设定、人物性格与关系、核心剧情、关键事件链、交互机制、专属玩法系统、主要势力 / 组织结构等。排版美化、状态栏格式、叙述规则、破甲、输出模板、示例等辅助模块不属于有效设定，不计入本细则各条款项下的比对与认定范围。本细则中“有效设定内容”“核心层有效设定”“有效设定模块”等表述，均以本定义为基准。
— 卡的状态 —
- 将该卡设为私密：将角色卡转为私密状态，不再对外公开展示或进入公开访问范围；已开始游玩的用户不受影响，可继续游玩。私密期间角色卡不再产生收益电量；作者仍可通过主动分享私密链接供他人访问体验。因违规处理导致角色卡被设为私密期间所产生的榜单排名变动、流量损失及曝光中断，由作者自行承担，平台不予补偿；但经申诉确认属于平台判定错误的除外。
- 重新公开：经平台要求整改的角色卡，作者完成相应整改并经审核组确认后，可由私密状态恢复为公开状态。除本细则另有规定外，整改未完成或未经确认前，角色卡不得重新公开。
- 有效更新：指角色卡在原有基础上进行了足以构成“版本跃迁”的实质性内容升级，是适用“去旧留新”处理的前提条件，具体判断标准见第 2.3 条。
- 去旧留新：当新版本被认定为“有效更新”时，平台保留新版公开，并将旧版按上述“将该卡设为私密”处理；该处理不扣除旧版角色卡已获得的收益电量。
- 转载：角色卡标记为转载属性，并按规则标注原作者信息；转载卡不会产生收益电量。
- 换绑：将角色卡的归属从原发布账号转移至实际作者账号，由实际作者作为该卡的署名作者与权益主体。
— 处罚机制 —
- 收益电量：角色卡在公开状态下，因用户消耗电量与其进行互动而产生的平台收益，归属于发布该角色卡的作者账号。收益电量为平台内部虚拟资产单位，具体使用规则以平台说明为准。
- 扣除收益电量：扣除该角色卡截至处理生效时点已经获得的收益电量。除本细则另有明确说明外，扣除范围以该违规角色卡自身已获得的收益电量为限；若涉及多张角色卡或多个账号共同违规，则按对应条款对相关角色卡分别处理。本细则中“扣除全部收益电量”“扣除 X% 收益电量”等表述，均以本定义为基准计算。
- 账号电量余额：指该账号名下所有电量的合计，包括收益电量、充值电量及其他奖励电量。
- 账号电量负余额：因扣除操作产生的应扣电量超出可扣范围的，差额以负值记录于该账号。负余额期间账号基本功能不受影响，后续获得的收益电量将优先抵扣负余额，直至归零后方可正常积累与使用。
- 移除榜单勋章：撤销角色卡已获得的日榜、周榜或月榜排名勋章（包括第一名、前三名、前十名等各级别勋章）；移除后该勋章不再展示于对应角色卡，且不予补发或恢复，但经申诉确认属于平台判定错误的除外。
- 封禁投递权限：账号失去投稿 / 公开投递权限；其他功能不受影响，除非本细则另有说明。
— 影响认定 —
- 对社区秩序造成明显负面影响：指违规行为在社区内部引发可观察的秩序破坏，综合参考以下情形：角色卡评论区出现大量因违规内容直接引发的对立性讨论；因违规争议导致社区出现持续性攻击、引战或骚扰行为；违规行为在社区内被大范围传播扩散，持续引发站队、对立或围绕该违规行为的集中讨论，导致正常创作反馈环境受到实质干扰。舆论声量、争议热度或举报数量可作为参考因素，但不作为本项认定的唯一依据。
- 对平台内容生态造成明显负面影响：指违规行为在更宏观层面对平台创作环境、分发公平或声誉产生可量化的实质损害，综合参考以下情形：对创作者公平竞争环境造成可量化的实质影响；形成可复制的不当获利路径，诱导其他创作者效仿，破坏平台内容分发秩序；对平台整体声誉或用户信任造成可观察的实质损害。

1.4　裁量与证据原则
- 平台在接到用户举报后，将结合查重结果与证据链进行综合判断。若违规行为对社区秩序或平台内容生态造成明显负面影响（定义见第 1.3 条），平台可按更高档处理。
- 平台在具体处理时，可结合以下因素进行从轻或从重判断：是否首次违规、是否主动说明与配合核实、是否及时整改、是否存在主观规避、是否对社区秩序或平台内容生态造成负面影响及其程度、是否存在多账号协同、是否删除证据或干扰调查、是否存在反复违规或组织化行为。

1.5　违规处理的时效
平台对违规行为的处理不设追溯期限。无论角色卡已公开多久、违规行为发生多久，一经查实，平台均有权依据本细则进行处理。

1.6　审核通过的效力范围
- 角色卡通过日常审核，仅代表该卡在提交审核时的公开展示内容符合当时的基本投递要求，不构成平台对该卡全部内容的合规性背书，亦不代表该卡在后续公开期间的内容及相关行为永久符合平台规则。
- 作者对其角色卡全部公开内容及后续公开行为负有持续的合规责任，不得以“已通过审核”“平台此前未作处理”等理由作为免责依据。

1.7　整改复审程序
因违规被设为私密的角色卡，整改完成后根据处理方式适用以下两种复审路径：
- 普通违规整改：处罚通知未要求通过专项复审渠道处理的，作者完成相应修改后，可重新提交日常投递，经日常审核通过后恢复公开，时限参照平台日常审核节奏执行。
- 专项督促整改：处理结果附带平台明确列出的具体整改要求的，作者完成整改后须通过专项复审渠道向审核组提交复审申请，不进入日常审核队列。审核组将在收到申请后 48 小时内作出复审结果；如遇特殊情况需延期，审核组应主动告知作者预计完成时间。
- 复审结果分为两种：确认整改完成并恢复公开；或认定整改仍不符合要求，继续设为私密并告知作者需进一步修改的具体内容。复审未通过的，作者可在再次整改完成后重新提交复审申请，时限同上。

1.8　已公开角色卡的重新发布
本条所称“重新发布”，是指作者拟将已公开角色卡撤回，并另行以新卡形式公开投递的行为，不包括直接对现有公开卡进行内容更新。
已公开的角色卡若需撤回后重新作为新卡发布，须提前向审核组报备并说明申请理由。每张角色卡仅限一次重新发布机会，审核组将综合以下因素判断是否批准：
- 角色卡的历史数据表现（对话量、收益电量等）；
- 距上次公开的时间间隔；
- 申请理由的合理性与必要性；
- 其他审核组认为需要参考的特殊情况。
审核组在收到申请后将告知审批结果；理由不充分或不符合条件的申请将被拒绝。
经审核认定符合第 2.3 条“有效更新与去旧留新”条件的，按第 2.3 条处理，保留新版公开，将旧卡设为私密且不扣除旧卡收益电量。
不属于第 2.3 条“有效更新与去旧留新”情形，但基于其他合理、必要理由经审核组批准重新发布的，旧卡将被设为私密并扣除其全部收益电量，该处理不可回撤。
经本条批准重新发布的，不因重新发布行为本身适用第 2.1 条或第 2.2 条；如另存在独立违规事实，仍按相应条款处理。
作者未经批准自行删除旧卡，或进行其他影响旧卡数据、收益、公开状态的操作，由此产生的损失由作者自行承担，不影响审核组对新卡作出处理。
注：
未经报备擅自重新发布的（包括尚未获得审批结果即抢先公开新卡，或已删除旧卡的情形），审核组将结合其是否通常符合批准条件、是否存在主观规避、是否初犯及是否主动说明并配合处理等因素综合判断，据此区分处理：
- 经核实通常可获批准、且不存在主观规避的：按本条对应的批准重新发布方式处理。符合第 2.3 条“有效更新与去旧留新”条件的，按第 2.3 条处理；不属于有效更新但通常可基于其他合理理由获批重新发布的，将旧卡设为私密并扣除其全部收益电量，新卡予以保留。
- 经核实不符合批准条件，或存在主观规避情形的：按第 2.1 条处理，将新卡设为私密并扣除其全部收益电量。
- 多次擅自重发的，视情节参照第 5.1 条从重处理。

第二章　内容类违规

2.1　重复投递（相同角色卡重复发布）
触发条件
- 已公开的角色卡再次以新公开卡形式发布，且内容实质相同。
- 仅更换封面、修改标题、微调排版或少量措辞修改的，不构成“新卡”，原则上认定为重复投递。
处理方式
- 将被认定为重复的新卡设为私密。
- 扣除该新卡的全部收益电量。
- 移除榜单勋章（若有）。

2.2　不符合新卡条件（少量改动重发 / 整卡同质化重复发卡）
触发条件
- 角色卡仅进行轻微调整后重新作为新公开卡投递，且改动不足以构成“新卡”或“有效更新”。
- 轻微调整包括但不限于：替换部分词句、角色设定小幅修改、局部内容扩充、细节替换与参数微调、增补状态栏或表达规则，但整体设定框架、世界观结构、主角定位、核心冲突与主要体验路径仍与已有作品高度重合。
- 与作者名下已有角色卡相比，新卡虽存在局部新增或扩写，但主要角色关系、核心剧情结构、互动目标与玩家体验仍可被已有作品实质替代，不足以支撑独立新作定性的，视为同质化重复发卡。
- 角色卡设定字数尚未达到上限，或原卡仍有内容补充空间的，作者应优先在原卡更新，而非另行作为新公开卡发布。
认定说明
- 本条重点判断“新卡整体是否成立”：若新卡与旧卡在整体体验上高度互相替代，原则上适用本条。
- 若新卡已形成明显不同的主角定位、核心冲突、主要角色主轴或剧情方向，但存在大量复制移植其他已发卡有效模块的，优先转入第 2.21 条“有效设定多卡复用”评估。
- 若同一角色卡同时存在整卡同质化与模块复制移植情形，可根据第 5.2 条处罚竞合处理，原则上适用较重处理。
处理方式
- 将该新公开卡设为私密。
- 扣除该新卡的全部收益电量。
- 移除榜单勋章（若有）。
- 要求作者在原卡更新；若属同质化重复发卡，该卡不予重新公开。

2.21　有效设定多卡复用
触发条件
- 同一作者名下存在两张及以上公开角色卡，存在大量相同或高度雷同的有效设定内容（范围见第 1.3 条），包括直接复制、移植，或仅更换角色名、职业、地点、参数及少量词句后再次使用。
- 单张卡对作者其他已发卡的有效设定内容复用比例达 50% 及以上的，可认定为复用卡；不足 50%，但在角色设定、世界观或其他有效设定维度中存在多处明显复用，已影响该维度独立性的，可综合认定。
- 仅题材、角色类型、常见性格、世界观类型、地图结构或创作模板相似的，不认定为复用；判断重点在于实际有效设定内容是否被原样或轻微改写后重复使用。
- 同人系列或共享世界观作品的合理公共设定沿用不当然构成复用；超出合理共享范围的大量内容复用，仍按本条判断。
处理方式
- 将被认定为复用的角色卡设为私密（同一组复用卡中，原则上以作者最早公开的角色卡作为保留对象）。
- 督促作者对复用的有效设定内容进行实质性差异化改写。
- 对每张被认定为复用并设为私密的角色卡，分别扣除该卡自身已获得收益电量的 50%。
- 移除榜单勋章（若有）。
注：
- 本条与第 2.2 条的区分，以“整卡体验是否具有独立性”为主要判断依据：整体体验高度互相替代的，优先适用第 2.2 条；整体方向已明显不同但存在大量有效设定模块复用的，优先适用本条。

2.3　有效更新与去旧留新
适用条件（满足至少两项即可纳入评估）
- 世界观大幅扩展。
- 角色设定大幅补充。
- 剧情结构 / 交互机制 / 玩家核心体验上出现实质变化。
- 其他足以构成“版本跃迁”的实质内容变化，以平台综合判断为准。
处理方式
若经查重与综合判断符合“有效更新”，采取“去旧留新”处理：
- 将旧卡设为私密。
- 不扣除旧卡任何收益电量。
- 不影响已游玩玩家继续游玩。
- 作者仍可通过主动分享旧卡私密链接供他人访问体验，但不会获得收益电量。
注：以下情形，原则上不计入“有效更新”认定的实质扩展、补充或调整范畴：
- 仅将既有内容重新拆分、归类或整理为结构化字段、清单或标签形式，未改变核心运行逻辑或体验目标的；
- 数量层面的堆叠或扩充（如场景、道具、素材、分支条目增加），但所依托的仍是同一套既有机制或触发逻辑的；
- 对既有数值、参数进行具体化、量化或幅度调整，但未改变其底层运行规则的；
- 补充背景、花絮、说明性描写，但未改变角色定位、核心冲突或主要体验路径的。
上述情形单独或组合出现，均不视为满足本条“有效更新”门槛；如需评估是否达标，仍应回归世界观框架、主角定位、核心冲突与体验逻辑等实质维度综合判断。

2.4　分区标注不符
触发条件
- 角色卡所选分区与作品实际主要内容不符，包括分区错标或明显不相符的情形。
- 普通分区应以作品的核心设定、主要角色关系、主要剧情方向或核心互动体验为判断依据；仅存在相关角色、情节或次要元素，但未构成作品主体或主要内容的，不当然要求标注对应分区。
处理方式
档 A-1（普通分区标注不符）
- 不涉及敏感分区的一般分区错标、应标未标或与实际主要内容明显不符，且未构成第 2.5 条虚假包装 / 误导性投递的。
- 审核组可直接将该卡调整至正确分区，或通知作者自行调整。
- 不设为私密，不扣除收益电量。
档 A-2（敏感分区标注不完整或归类错误，且已尽公开提示义务或无规避迹象）
存在敏感分区应标未标或错标情形，未构成档 C 情形，且符合下列任一：
- 作者已在标题、简介、第一句话 / 开场白或自定义标签中，对该项敏感元素作出明确、具体的提示，玩家在进入游玩前可据此识别；
- 作品已实际标注部分敏感分区，仅遗漏其中一项或数项，且无隐藏敏感属性、规避筛选的迹象；
- 相关内容确属敏感分区范围，作者已标注同一关系结构下的相邻分区，仅在具体归类上判断有误（如 NTR 与类NTR 之间的错标，判断标准见《分区与标签使用规范》第 5.21 条）。
处理方式
- 审核组可直接将该卡补充或调整至正确的敏感分区，或通知作者自行调整；
- 不设为私密，不扣除收益电量。
档 B（敏感内容未投递至正确分区）
- 角色卡内容包含敏感元素，但作者未投递至对应敏感分区，且不符合档 A-2 情形的。
- 将该卡设为私密。
- 督促作者调整至正确分区。
档 C（档 B 情形并对社区秩序或平台内容生态造成明显负面影响）
- 将该卡设为私密。
- 督促作者调整至正确分区，并补充相应风险提示。
- 扣除该卡 50% 的收益电量。
- 移除榜单勋章（若有）。
注：
- 敏感分区的范围与强制标注要求，参照《分区与标签使用规范》第 1.2 条、第 5.3 条执行；NTR / 类NTR 另参照该规范第 5.21 条。
- 已对社区秩序或平台内容生态造成明显负面影响的，不适用档 A-2；但作者已尽档 A-2 所列提示义务或不存在主观规避迹象的，可酌情按档 B 处理。
- 若普通分区标注不符同时构成对作品核心体验的明显误导，按第 2.5 条处理。

2.5　虚假包装 / 误导性投递
触发条件
- 角色卡的标题、简介、第一句话、封面、分区、标签或其他公开展示信息，与玩家实际核心体验、主要互动逻辑、剧情走向存在明显不符，足以对玩家形成错误预期。
- 故意弱化、隐藏或回避会显著影响玩家体验判断的关键要素（如主控受辱、背叛 / NTR 倾向、明显负向互动结构等），使玩家在进入游玩前无法作出基本判断。
- 以“纯爱 / 无牛”等包装高争议、高压、强负面体验内容，或通过模糊描述、误导性文案刻意误导玩家。
- 其他经平台综合判断，属于对作品核心体验进行明显包装性误导、足以造成用户混淆或误入的情形。
处理方式
档 A（一般情况）
- 将该卡设为私密。
- 督促作者补齐相应分区、风险提示，或修改标题、简介、第一句话、分区等公开展示内容，使其与实际核心体验相符。
档 B（对社区秩序或平台内容生态造成明显负面影响）
- 将该卡设为私密。
- 督促作者修改标题、简介、第一句话、分区、标签等公开展示内容，使其与实际核心体验相符，并补充相应风险提示。
- 扣除该卡 50% 的收益电量。
- 移除榜单勋章（若有）。

2.6　作者身份虚假包装 / 真人感误导性引流
触发条件
- 角色卡封面、配图、简介、第一句话、设定或评论区置顶等公开展示内容中，使用非本人图片、素材或形象，并通过文字描述、暗示性表达或互动方式，刻意引导用户形成“图片或角色形象与作者本人存在真实对应关系”的预期。
- 在角色卡相关公开内容或评论区中，以“作者本人原型”“作者真实经历”“本人自拍”等方式进行引流或形象构建，但实际使用的图片或素材并非本人，且未作明确的虚构声明。
- 通过公告、评论区互动或其他公开说明，持续强化“作者本人感”，形成以作者真实身份为核心的用户依赖关系，并借此实现引流或收益获取目的。
- 其他经平台综合判断，属于以作者身份真实性为包装手段、对用户形成明显误导的情形。
处理方式
档 A（一般情况）
- 将该卡设为私密。
- 督促作者删除或修改相关误导性表述；若继续使用相关图片，须明确说明仅为形象参考、并非本人。
档 B（对社区秩序或平台内容生态造成明显负面影响）
- 将该卡设为私密。
- 督促作者删除或修改相关误导性表述及引导对立的公告说明。
- 扣除该卡 50% 的收益电量。
- 移除榜单勋章（若有）。

2.7　角色年龄数字限制
触发条件
- 角色卡的标题、简介、第一句话或开场白中出现未满 18 岁的具体年龄数字。

注：用于追忆性、过去式描述的年龄数字（如“她在十七岁那年……”等回忆性表述），可结合上下文酌情评估，不当然视为违规。

2.8　幼态主题肉向角色卡的成年声明要求

2.9　涉及中国近现代敏感题材或真实人物
触发条件

2.10　角色卡图片合规要求

处理方式

- 督促作者对相关图片进行打码、更换或去除水印等处理。

2.11　违规引流

- 引流形式包括但不限于：其他平台 / 网站名称或链接、QQ 群 / 微信群 / TG / DC 等其他社群信息、个人社交账号、二维码、邀请码、ID 或引导关注的账号信息等。

档 B（多次督促不改或再次违规）

- 移除榜单勋章（若有）。

注：是否构成“引流”，以平台基于内容指向、表达意图及实际效果的综合判断为准；正常的世界观引用、致敬类标注（如“参考自 XXX 作品”）不当然视为引流。

第三章　原创性违规

3.1　抄袭 / 搬运他人作品
触发条件
- 非原创作品却标记为原创。
- 盗用或未经授权直接搬运他人作品。
- 复制其他作者角色卡设定、结构或大量文本。
- 其他经平台综合判断，属于抄袭、搬运或重复他人作品的情形。
处理方式
- 将该卡设为私密。
- 扣除该卡的全部收益电量。
- 移除榜单勋章（若有）。
注：
- 平台判断抄袭 / 搬运时，将综合参考文本重复率、内容相似度，以及核心设定、人物关系、剧情结构、关键事件链、特殊机制、关键表达段落、表达结构与整体体验是否存在高度重合。
- 重复率与相似度是重要参考因素，但平台将优先关注有效内容层面的实质重合，而非仅以字面重复比例作为唯一依据；仅题材、分区、常见元素相同，不当然构成抄袭。
- 属整卡抄袭 / 搬运的，经核实后原作者可申请将该卡换绑至本人账号并恢复公开，换绑后正常产生收益电量；原作者不申请换绑的，该卡不予公开。原作者已自行发布同一作品的，不另行换绑。

3.2　第一句话抄袭他人作品
触发条件
- 第一句话直接复制粘贴他人小说 / 文本内容，或照搬多段且未做任何实质改写润色。
处理方式
- 将该卡设为私密。
- 扣除该卡 50% 的收益电量。
- 移除榜单勋章（若有）。
- 督促作者更改并补充引用来源。
统一引用格式（模板）
- 创作声明：本角色卡的第一句话 / 开场白部分内容引用自 XXX（作品名称），作者 XXX。

3.3　高度借鉴他人作品且未做引用
触发条件
- 角色卡的核心层有效设定明显参考他人作品或角色卡，且未作引用声明。
处理方式
- 将该卡设为私密。
- 扣除该卡 50% 的收益电量。
- 移除榜单勋章（若有）。
- 作者需在简介 / 第一句话 / 开场白任选其一添加参考来源；拒不添加的，该卡不予重新公开。
统一引用格式（模板）
- 创作声明：本角色卡的核心设定 / 关键结构参考自 XXX 角色卡（角色卡名字），作者 XXX。

3.4　美化 / 状态栏模板复制挪用
触发条件
- 角色卡的美化内容，如状态栏、按钮样式、排版框架、HTML / CSS 美化组件等，经该美化内容的原创作者本人向平台提出投诉，认定为未经授权直接复制挪用其原创美化内容，且未做任何实质性修改。
处理方式
- 将该卡设为私密。
- 扣除该卡 25% 的收益电量。
- 督促作者修改 / 替换；如涉及参考他人模板，需按平台要求补充来源 / 授权说明。
统一引用格式（模板）
- 创作声明：本角色卡的状态栏 / 美化样式 / HTML 排版 / 按钮样式参考或使用了 XXX 模板 / 角色卡的美化结构，作者 XXX。
注：
- 本条仅受理美化内容原创作者本人，或能够提供有效授权证明、代表原创作者本人提出的投诉。非原创作者本人且无法证明代理关系的第三方，以“疑似使用了某处美化模板”为由举报的，不触发本条款。
- 原作者应提供该美化内容的原创证明，如原始代码 / 工程文件、更早的公开发布记录或其他足以证明创作归属的材料。证明不足的，审核组可要求补充；仍无法证明的，不触发本条款。

3.5　未经授权使用他人原创图片
触发条件
- 角色卡封面、配图、状态栏图片或其他作品内嵌图片，经图片原创作者本人向平台提出投诉，认定为未经授权使用其原创图片（包括但不限于原创作者自行绘制、自行 AI 生成或其他形式创作的图片）。
处理方式
- 将该卡设为私密。
- 督促使用方作者更换相关图片。
注：
- 本条仅受理图片原创作者本人，或能够提供有效授权证明、代表原创作者本人提出的投诉。非图片原创作者本人且无法证明代理关系的第三方，以“疑似使用了某处图片”为由举报的，不触发本条款。

3.6　授权改编作品原创属性不当 / 授权内容高度复用
触发条件
- 作者经原作者授权对其作品改编 / 扩写后投递，但核心层有效设定大量逐字 / 近原样挪用原作，未作实质性改写或形成自身的原创性表达，逐字、近逐字或轻微改写复用比例达 50% 及以上。
处理方式
- 将该卡设为私密。
- 扣除该卡 50% 的收益电量。
- 移除榜单勋章（若有）。
- 督促作者在简介 / 第一句话 / 开场白任选其一，补充完整、清晰的授权改编声明。
统一引用格式（模板）
- 创作声明：本角色卡基于 XXX（作品名称）授权改编 / 扩写，原始核心设定来源于原作者 XXX。
注：
- 本条以已获有效授权为前提。未获授权的复制 / 搬运，作者无法提供有效授权证明，授权不实或伪造，或明显超出授权范围使用原作内容的，按第 3.1 条处理。
- 若虽有授权，但该卡几乎完全照搬原作，仅作标题、封面、格式、少量措辞或局部补句调整，不具备独立改编内容的，按第 4.1 条处理，并按转载、授权转载、换绑或平台认可的其他非独立原创方式处理。

第四章　账号与行为类违规

4.1　非作者本人原创发卡（代发 / 买卡 / 冒名投稿 / 约稿代笔）
触发条件
- 投稿账号并非作品实际作者，却以本人原创身份投递作品，涉及代发、买卡、冒名投稿、约稿代笔等情形，包括以金钱交易方式取得他人作品后发布、委托他人代为撰写后以本人原创身份投递、冒用他人身份投稿等。
- 为他人撰写角色卡成品（完整角色卡、核心角色设定、世界观框架或主要有效设定模块），且明知或应知对方将以本人原创身份投递的，构成代笔。
对投稿方的处理方式
- 将该卡设为私密。
- 扣除该卡的全部收益电量。
- 移除榜单勋章（若有）。
对代笔方的处理方式
- 首次查实代笔行为的，封禁代笔方投递权限 30 日，并扣除其当前账号电量余额的 50%；按 50% 计算后不足 10 万电量的，按 10 万电量扣除。
- 存在收费代笔、公开接单、批量 / 长期代笔、为多人提供代笔服务，或以电量、对话量、榜单成绩等站内收益作为宣传、定价、保底或补单条件的，视为商业化代笔，首次查实即永久封禁投递权限，并扣除其当前账号电量余额的 50%；按 50% 计算后不足 10 万电量的，按 10 万电量扣除。
- 受到处理后再次实施代笔行为的，永久封禁投递权限，并参照第 5.1 条从重处理。
主动说明与配合核实
- 投稿方在该卡被处理后主动向审核组说明代笔情况，如实提供代笔方的身份信息、联系方式、交易与沟通记录及所涉代笔范围等相关证据并配合核实，经核实属实的，可免于扣除该卡的收益电量；已扣除的予以返还。
- 提供虚假信息、伪造证据或指认与事实不符的，不适用本款，并按第 4.4 条处理。
注：
- 不得以“双方协商一致”“存在金钱交易”“对方自愿提供作品”或类似理由作为免责依据。
- 经原作者明确授权的转载、协助整理或代为上传，不当然等同于原创投稿；发布账号不得将该作品标记为本人原创或获取原创收益，具体应按转载、换绑或平台认可的授权发布方式处理。
- 教学、指导、审稿、提出修改意见、提供公开模板或通用素材，不属于代笔。
- 未经实际作者许可擅自盗用、搬运他人作品投递的，不适用本条，按第 3.1 条处理。

4.2　多号发卡
触发条件
- 同一作者使用多个账号发布角色卡、获取角色卡收益电量，或通过多个账号伪装为不同创作者身份，制造多个独立作者、不同作品来源或不同社群影响力的假象，以达到投稿、收益获取、引流或规避平台“一名作者仅可使用一个账号发卡”管理规则的目的。
- 平台将根据账号注册信息、登录 IP、作品风格、账号关联性、投稿记录、收益获取情况及其他后台数据，综合判断多个账号是否实际归属于同一作者或受同一作者控制。
处理方式
- 将相关账号名下所有角色卡全部设为私密。
- 扣除相关账号所有角色卡的全部收益电量。
- 移除榜单勋章（若有）。
- 封禁相关账号的投递权限。
- 仅保留最早注册的账号，其余账号按规则处置。
注：
- 平台不允许同一作者通过多个账号分别发卡。是否构成多号发卡，以平台基于上述数据与证据链的综合判断为准。
- 作者不得以“账号是朋友的”“只是帮忙发布”等理由规避责任。若多个账号实际服务于同一作者发卡、收益获取或规则规避目的，平台可按行为实质进行认定。

4.3　刷对话量 / 刷电量
触发条件
- 角色卡作者本人或与其存在关联关系、利益关系、协同行为的账号，通过本人账号、小号、关联账号、互刷账号、代刷账号或其他方式，对指定角色卡制造异常对话量、电量消耗、收益，或刻意制造热度数据、榜单表现及其他非自然曝光优势。
- 相关行为足以影响角色卡自然流量增长、收益公平、榜单秩序或社区公平竞争环境。
- 平台将结合有关账号的电量消耗记录、操作时间间隔、聊天内容、账号关联性、行为集中度及其他后台数据进行综合核实与判断。
处理方式
- 将涉及刷对话量 / 刷电量的角色卡设为私密。
- 扣除该角色卡的全部收益电量。
- 移除榜单勋章（若有）。
- 在扣除该角色卡收益电量之外，额外扣除违规账号当前账号电量余额的 50%；按 50% 计算后不足 10 万电量的，按 10 万电量扣除。
- 情节严重、存在多账号协同、组织化刷量、反复违规或规避处理的，平台可参照第 4.2 条“多号发卡”及第 8.1 条“未尽事项与补充处理”从重处理。
注：
- 是否构成刷量，以平台基于上述数据与证据链的综合判断为准。正常用户游玩、自然传播、作者正常测试角色卡，不当然视为刷量；但若测试行为明显超出合理频率、持续时间、消耗规模，或与收益获取、榜单冲刺、异常曝光结果存在明显关联，平台仍可按刷量行为综合认定。
- 作者不得以“账号并非本人操作”“朋友自愿支持”“只是测试角色卡”等理由规避责任。若相关账号与作者存在明显关联、协同行为或收益指向关系，平台可按行为实质进行认定。

4.4　虚假举报与干扰审核
触发条件
- 提交明显与事实不符、伪造证据或恶意针对特定作者的举报或投诉。
- 自导自演、组织化举报、利用举报机制赚取奖励或干扰他人作品分发。
- 删除证据、误导调查、串供、阻碍审核组核实工作的其他行为。
处理方式
- 视情节轻重，回收相关奖励、封禁举报权限。
- 情节严重的，封禁投递权限，并按本细则其他相关条款合并处理。
注：因错误举报导致他人角色卡被错误处理的，平台应当及时撤销原处理，恢复角色卡公开状态，返还已扣除的收益电量，并撤销因该处理产生的账号电量负余额。

4.5　干扰审核秩序
触发条件
- 在角色卡的标题、简介、第一句话、设定或其他公开内容中，以言语辱骂、威胁或攻击审核组的方式表达对抗情绪。
- 角色卡经审核组明确指出违规内容并要求整改后，未作任何实质修改即在短时间内反复重新提交送审，经多次提醒仍不停止。
- 其他经平台综合判断，属于故意消耗审核资源、扰乱正常审核秩序的行为。
处理方式
档 A（首次或情节较轻）
- 正式警告，要求停止相关行为。
档 B（警告后仍继续，或情节较重）
- 封禁投递权限。

第五章　累犯与处罚竞合

5.1　累犯加重
- 同一作者累计 2 次及以上触犯第 3.1 条（抄袭 / 搬运）的，除按该条款处理外，另行封禁投递权限，并扣除该作者名下所有角色卡的全部收益电量。
- 同一作者累计 2 次及以上触犯本细则同一条款其他违规情形的，平台可结合违规性质、频次、主观恶意及对社区秩序或平台内容生态的负面影响程度，从重处理，具体措施包括但不限于封禁投递权限、扣除相关角色卡收益电量或移除榜单勋章等。

5.2　处罚竞合
- 同一角色卡或同一账号同时触犯多项违规条款的，平台可根据行为性质、违规目的、实际影响及证据链，选择适用较重条款，或对不同违规行为分别处理、合并执行。
- 涉及收益、电量、投递权限等处罚的，平台可结合各违规行为的独立处罚标准、实际影响范围及从重情节，合并计算执行；合并执行的处罚总量不低于各独立违规中最重的单项处罚标准。

第六章　举报

6.1　举报渠道
用户可前往平台官方 TG / DC 社群的“举报违规角色卡”专区提交举报。

6.2　举报信息
举报时应提供以下内容：
- 被举报角色卡的身份信息——可直接发送角色卡截图（推荐），或文字提供角色卡的链接、ID、名称等。
- 涉嫌违反的具体条款或违规情形的简要描述。
注：
- 审核组将依据举报者提供的信息定位角色卡并核实违规内容；若有补充材料（如原始来源链接、对比截图等），可一并发送以协助核实。
- 第 3.4 条、第 3.5 条仅受理原创作者本人或其有效代理人的投诉，第三方举报不予受理，亦不适用第 6.4 条举报奖励。此类投诉除本条所列信息外，另需提供本人为该内容原创作者的证明材料；代理人投诉的，另需提供有效代理证明。

6.3　举报处理
- 审核组在收到举报后将进行核实与判断，并根据本细则相关条款对违规角色卡作出处理。
- 核实结果及处理情况由审核组依规执行；举报者可在合理期限内向审核组询问处理进度。

6.4　举报奖励
经审核组核实属实的违规角色卡，举报者可获得电量奖励。举报者须在举报时明确指出相应违规事实，但无需准确判断具体适用条款；奖励档位以审核组最终认定的违规条款为准。
奖励分档
- 300 电量档：第 1.8 条（未经报备擅自重新发布）、第 2.1 条（重复投递）、第 2.2 条（少量改动重发 / 整卡同质化重复发卡）、第 2.21 条（有效设定多卡复用）、第 3.1 条（抄袭 / 搬运他人作品）、第 3.2 条（第一句话抄袭他人作品）、第 3.3 条（高度借鉴他人作品且未做引用）、第 3.6 条（授权改编原创属性不当 / 授权内容高度复用）、第 4.1 条（非作者本人原创发卡）、第 4.2 条（多号发卡）、第 4.3 条（刷对话量 / 刷收益电量）。
- 200 电量档：第 2.4 条档 B、档 C（敏感内容未投递至正确分区）、第 2.5 条（虚假包装 / 误导性投递）、第 2.6 条（作者身份虚假包装 / 真人感误导性引流）、第 2.11 条（违规引流）。
- 100 电量档：第 2.4 条档 A-1（普通分区标注不符）、档 A-2（敏感分区标注不完整或归类错误）、第 2.7 条（角色年龄数字限制）、第 2.8 条（幼态主题肉向角色卡的成年声明要求）、第 2.9 条（涉及中国近现代敏感题材或真实人物）、第 2.10 条（角色卡图片合规要求）。
分档依据
- 300 电量档：判定成立须引入被举报角色卡之外的比对对象或后台数据（作者名下其他角色卡、他人角色卡、站外原始作品、账号关联记录与电量消耗记录等），日常审核在送审环节无法自主发现。
- 200 电量档：判定证据位于角色卡内部，但须实际游玩，或通读设定与世界书方可确认。
- 100 电量档：判定证据位于角色卡的公开展示层（标题、简介、第一句话 / 开场白、封面及作品内嵌图片、所选分区），无需游玩或比对即可识别。
发放规则
- 奖励以“角色卡 × 违规条款”为计算单位：同一张角色卡经核实成立的每一项违规条款，各自构成一个独立的奖励单位，按该条款对应档位单独计算，不设合计上限。
- 奖励仅限举报者在举报时明确指出并经核实成立的违规项；审核组在核实过程中另行发现的其他违规，依本细则处理，但不构成该举报者的奖励单位。
- 同一违规行为涉及多张角色卡的（如第 4.2 条多号发卡），按经核实成立该项违规的角色卡张数计算，每张角色卡对应一份该条款档位的奖励。
- 各奖励单位独立发放：同一奖励单位被多人举报且均属实的，发放给最早提交有效举报的用户，其他举报者不重复发放；同一张角色卡的不同违规项由不同举报者分别举报并成立的，各举报者按其举报成立的违规项分别获得奖励。
- 依第 5.1 条对作者名下未单独构成违规的其他角色卡作出的处理，不构成独立的奖励单位，不计入奖励计算。
- 第 2.3 条、第 3.4 条、第 3.5 条、第 4.4 条、第 4.5 条及第五章各条，不适用本条举报奖励。
- 举报内容经核实不属实、证据不足或存在虚假举报情形的，不发放奖励；情节严重的按第 4.4 条处理。

第七章　申诉

7.1　申诉渠道
若用户对判定结果有异议，可通过平台官方 TG / DC 社群联系审核组进行申诉。

7.2　申诉时限
申诉应自处罚通知送达之日起 7 日内提出。逾期未提出申诉的，视为放弃申诉，原处理结果维持。除审核组另有决定外，申诉期间原处理措施继续执行。

7.3　申诉材料
申诉时应提供以下材料：
- 申诉账号信息及涉及的角色卡身份信息——可直接发送角色卡截图（推荐），或文字提供账号 ID、角色卡链接 / ID / 名称等。
- 对判定结果的具体异议及理由。
- 支持申诉理由的证据材料（如原创证明、授权凭证、聊天记录等）。
注：审核组将依据可获取的信息进行核实；若信息不足以支持申诉判断，审核组可要求申诉者补充材料。

7.4　申诉处理
- 审核组将基于既有证据与判定依据作出一对一回复，回复时限原则上为 3 日内。
- 申诉结果为维持原处理或调整处理的，审核组应说明依据。
- 对申诉结果仍有异议的，作者可在收到答复后 3 日内提出二次申诉。审核组将启动同行评审机制，由非原审理成员组成的复核小组进行评议，以确保处理结果公正一致；复核结果为最终结果。

- 对本细则未明确列举，但实质上破坏平台创作秩序、发布秩序、社区公平、内容合规或用户体验的行为，平台有权结合规则目的、证据情况及实际影响进行综合判断，并参照最相近条款处理。
- 若用户通过规避、拆分、变形等方式实施与本细则所禁止行为实质相同的行为，平台有权按照行为实质进行认定与处理，不以表面形式差异作为免责依据。

8.2　规则解释与适用
- 本细则由平台制定，具体执行、适用说明及申诉受理由审核组负责。
- 在具体执行中，平台将结合规则文本、证据链、行为性质、实际影响及历史处理口径进行综合判断；对于存在争议或规则边界不明的情形，平台保留进一步说明、补充规则适用口径及调整处理尺度的权利。

8.3　修订与公示
本细则的修订由平台发起，修订后将在官方渠道公示，自公示之日起立即生效，修订前已生效的处理结果不受影响。

# MMD 三段式页面布局框架

目标：提供一套当前 MMD 可复用的全局页面布局骨架，用于分享给其他制作者二次改造。框架只处理布局，不绑定角色、剧情、地图、世界观、图片资源或视觉主题。

## 1. 适用范围

- 平台：当前 MMD。
- 交付：`页面布局框架.json` 可作为 MMD 正则导入包。
- 结构：固定顶栏、动态主界面、底部按钮栏、原生顶栏拉片、侧边工具槽、通用弹层。
- 约束：不写旧版 MMD、本地酒馆或跨平台兼容分支；目标选择器确定后直接使用。

## 2. 页面结构

### 自定义顶栏

- `.app-top` 固定在视口顶部：`position: fixed; top: 0; left: 0; right: 0;`
- 顶栏内部用 grid/flex 分行，横向伸缩元素必须设置 `min-width: 0`。
- 长文本使用 `overflow: hidden`、`text-overflow: ellipsis` 或内部滚动，不允许撑破布局。
- 顶栏高度不写死，运行时读取 `.app-top.offsetHeight`。

### 主界面层

- `.app-main` 固定在顶栏和底栏之间：`position: fixed; left: 0; right: 0;`
- `top` 使用顶栏实际高度。
- `bottom` 使用底部按钮栏实际高度。
- 普通页面用 `overflow: auto`；需要全屏内容的页面可给当前 view 自行设置 `overflow: hidden`。
- 首页 `story` 保留原聊天正文，不显示主界面覆盖层。

### 底部按钮栏

- `.app-tabs` 初始写在 `.app-shell` 内，初始化时移动到 MMD 原生 `.chat-bottom`。
- 使用 `display: grid; grid-template-columns: repeat(4, minmax(0, 1fr));`
- 切换页面只改变按钮和 view 的 `is-active`，不改布局计算规则。
- 如果要改按钮数量，需要同步修改 DOM、CSS 的列数和 JS 中对应的 `data-app-page`/`data-app-view`。

## 3. 原生顶栏处理

- 不删除 `.topTabbar`。
- 给 `body` 添加 `.app-ui-enabled`。
- 默认将 `.topTabbar` 固定在顶部并移出视口：
  - `position: fixed !important;`
  - `transform: translateY(-100%);`
  - `opacity: 0;`
  - `pointer-events: none;`
- `.app-native-tools` 是原生顶栏拉片。
- 点击拉片切换 `body.app-native-open`。
- 原生顶栏打开后，拉片使用 `translateY(var(--app-native-h))` 下移，避免被原生顶栏盖住。
- 原生顶栏只是临时工具层，不参与 `.app-main` 的 top/bottom 计算。

## 4. 层级约定

| 层 | z-index |
|---|---:|
| 自定义顶栏 `.app-top` | 100 |
| 侧边工具 `.app-side-tools` | 100 |
| 原生 `.topTabbar` | 1022 |
| 原生顶栏拉片 `.app-native-tools` | 1024 |
| 主界面 `.app-main` | 1030 |
| 底部按钮栏 `.app-tabs` | 1040 |
| 输入区拉手 `.app-keyboard-handle` | 1041 |
| 通用弹层 `.app-modal` | 1050 |

## 5. 布局计算

必须使用实际高度，不写死：

```js
const topH = top.offsetHeight;
const bottomH = tabs.offsetHeight;
main.style.top = topH + 'px';
main.style.bottom = bottomH + 'px';
modal.style.top = topH + 'px';
modal.style.bottom = bottomH + 'px';
chat.style.setProperty('padding-top', topH + 'px', 'important');
```

需要监听：

- 自定义顶栏尺寸变化。
- 底部按钮栏尺寸变化。
- 原生 `.topTabbar` 尺寸变化。
- `window.resize`。

## 6. 可改造槽位

- 顶栏：替换 `.app-top-cell` 文本或改成图标、进度条、跑马灯。
- 页面：保留 `story` 作为原聊天正文，改造 `panel`、`list`、`map` 三个 view。
- 底栏：修改按钮文案和 `data-app-page`。
- 侧边工具：`.app-side-tools` 默认提供上下滚动按钮，可替换为预算、总结、目录等工具。
- 弹层：`.app-modal` 默认空容器，可用于详情、图片预览、确认面板。
- 输入区拉手：`.app-keyboard-handle` 用于折叠 `.chat-bottom` 中除框架按钮外的原生输入组件。

目标：在当前 MMD 中复刻一种三段式全局界面布局：自定义顶栏、主界面层、底部按钮栏。不要绑定具体角色、剧情、文案或视觉主题。

一、整体结构
1. 自定义顶栏固定在视口顶部：
   - position: fixed; top: 0; left: 0; right: 0;
   - z-index 低于主弹层也可以，因为主界面用动态 top 避开顶栏。
   - 顶栏内部可用 flex-column 分多行，每行用 grid/flex。
   - 所有横向伸缩容器必须 min-width: 0，长文本用 overflow hidden / ellipsis / 内部滚动，不允许撑破布局。

2. 主界面不要写死高度：
   - position: fixed; left: 0; right: 0;
   - top = 自定义顶栏实际 offsetHeight。
   - bottom = 底部按钮栏实际 offsetHeight。
   - 普通页面 overflow:auto；全屏页 overflow:hidden。
   - 页面切换只切换 view 的 is-active，不改变整体布局计算。

3. 底部按钮栏挂到 MMD 原有底部容器：
   - DOM 可以先写在自定义 shell 内，初始化时 appendChild 到 .chat-bottom。
   - 使用 display:grid; grid-template-columns: repeat(n, minmax(0, 1fr));
   - width:100%; z-index 高于主界面。
   - 主界面的 bottom 始终取按钮栏 offsetHeight。

二、原有 MMD 顶栏处理
1. 不删除 .topTabbar。
2. 给 body 加自定义启用类，例如 app-ui-enabled。
3. 默认把 .topTabbar 固定到顶部但移出视口：
   - position: fixed !important;
   - top:0; left:0; right:0;
   - transform: translateY(-100%);
   - opacity:0;
   - pointer-events:none;
   - z-index 高于自定义顶栏。
4. 另设一个小按钮作为“原生顶栏拉片”：
   - position: fixed; top:0; right:若干 px;
   - z-index 高于 .topTabbar。
   - 点击切换 body.app-native-open。
5. body.app-native-open 时：
   - .topTabbar transform: translateY(0); opacity:1; pointer-events:auto;
   - 拉片按钮 translateY(var(--app-native-h))，避免被原生顶栏盖住。
6. 原生顶栏是临时工具层，不参与主界面 top/bottom 计算。

三、层级建议
- 自定义顶栏：100
- 普通全屏辅助层：1000
- 原生 .topTabbar：1022
- 原生顶栏拉片：1024
- 主界面层：1030
- 底部按钮栏：1040
- 独立弹层/最高覆盖层：1050

四、布局计算
必须用实际高度，不要写死：
const top = topEl.offsetHeight;
const bottom = tabsEl.offsetHeight;
mainEl.style.top = `${top}px`;
mainEl.style.bottom = `${bottom}px`;

同时监听：
- 自定义顶栏尺寸变化
- 底部按钮栏尺寸变化
- 原生 .topTabbar 尺寸变化
- window resize

五、附加规则
- 给聊天正文容器设置 padding-top = 顶栏高度，避免原始剧情内容被自定义顶栏盖住。
- 底部按钮切换页面时，可关闭当前临时弹层。
- 不要添加兜底或兼容分支；目标平台选择器确定后直接使用。

# 悬浮小人设计器

一个单文件网页工具。打开 `index.html` 就能用，不需要安装、不需要联网、不上传任何东西到服务器。

做的是：**把一张精致立绘变成趴在聊天页边上、能拖能点会看你、还会跟着鼠标"活"起来的小人**，并导出成可以直接贴进 MMD 角色卡的代码。

三种做法，按推荐程度排：

| 模式 | 干什么 | 效果上限 |
| --- | --- | --- |
| **分层小人**（默认） | 上传你手上任何一张精致立绘，切成几块做视差 → 立体纸片人 | **等于你那张立绘的精美程度** |
| 上传立绘 | 用整张立绘 + 抠图 + 描边投影 + 3D 倾斜 | 同上，但没有视差 |
| 捏小人 | 按图片取色，用内置零件拼一只 Q 版小人 | 简笔画级别，只适合当快速草图 |

---

## 一、分层小人（推荐）

核心思路：**精致的形象只能来自"已经画好的图"，不可能来自程序实时拼装**。所以工具不生成形象，而是把你已有的立绘**拆成几块**，让每块按不同幅度跟着鼠标动 —— 头动得多、身体动得少，看起来就有了纵深。

参考 `视差示意.png`（左中右三帧 = 鼠标在左、中、右）。

### 怎么用

1. 左上角选「分层小人」
2. 点 **上传透明底立绘**。工具会先给一套默认切法（身体在下、头在上），直接在图上改就行
3. **在图上按住拖动**就能框一块；拖动框内部移动它，拖右下角小方块缩放
4. 每一块在下面调两个值：
   - **深度** —— 跟随鼠标的位移倍数，越大动得越夸张（0 = 完全不动）
   - **转头** —— 跟随左右摆动的旋转幅度，头部调大比较自然
5. 中间预览里移动鼠标看效果

### 三个要点

- **框之间留点重叠**，不然各块移动后会露出缝
- **列表靠后的层画在上面**，所以「头」要排在「身体」后面
- 默认给的深度是 身体 0.4 / 头 1.5，一般够用；想更夸张就拉大

### 为什么体积不会翻倍

每块并没有真的去切割图片：同一张图用 `background-position` 取出不同的一块，图片地址靠 `background-image: inherit` **只写一次**。所以切 10 块和切 1 块，卡片大小几乎一样（有测试专门盯这条）。

## 二、上传立绘（整张图）

不想分层、只想让整张立绘立起来时用这个。

1. 切到「上传立绘」，把图拖进虚线框
2. 点「自动抠背景」，或直接点缩略图上的背景处精确取色
3. **抠不干净就用「手动修饰」画笔**：弹窗里放大涂抹，**擦除**去掉多余背景、**恢复**把误删的部分从原图找回来；滑杆或滚轮调笔刷大小，涂错了点「撤销」（最多 10 步）
4. 想整个重来就点「还原」回到原图；背景差异大就调「容差」
5. 右侧「立体感」一栏：轮廓描边 / 轮廓投影 / 立体倾斜

抠图用的是**泛洪填充**：只删「和背景色相近 **且** 和图片边缘连通」的像素，所以角色身上的白衣服、白高光不会被一起打掉。

> GIF 不支持抠图（重编码会丢动画）。

## 三、捏小人（快速草图）

按上传的图取色，再用内置零件拼一只 Q 版小人：**5 发型 × 5 服装 × 5 配饰 × 6 表情 × 6 处配色**（见 `零件-*.png`）。

- 点「按图片取色」→ 工具先抠背景，再按区域猜配色（上部取发色、中上部取肤色、下部取服装色）
- 配色不一定全对（**瞳色经常不准**），用下面 6 个颜色选择器手动改
- 给「待机 / 点击 / 拖拽」三个状态各选一个表情，点「生成 3 个状态的小人素材」

**说实话**：这条路的天花板不高。零件是我用 SVG 手搓的，每个几行代码，做出来是简笔画层次——纯色填充、没有渐变、没有睫毛眼影、没有发丝分束。跟 QQ 秀那种（背后是美术团队画的图层）差着量级。**它的价值是"10 秒钟先有个大概形象"，要精致请走第一条路。**

## 参数速查

- **基础**：`class` 前缀、宽度、层级
- **初始位置**：靠左/靠右、靠上/居中/靠下 + 边距
- **待机动画**：呼吸、摇摆、浮动
- **拖拽**：可拖、限制屏幕内、拖动换素材、位置记忆、四边吸附
- **点击反应**：动画、冷却、台词轮换、气泡停留
- **鼠标跟随**：偏移强度、平滑度、感知半径（分层模式下这些指标由每层的「深度/转头」决定）
- **立体感 / 抠背景**：见上

## 贴进 MMD

1. 点「导出代码」→「**下载正则包 .json**」
2. 回创卡页，用「**导入正则**」把 json 导进去
3. 角色卡的 **`statusbar`** 字段填 `{{doll}}`
4. 保存，回聊天页看效果

正则包里装好了所需的**全部规则**，一次导入完事。手动建也行，导出面板里每条规则的名称/匹配式/替换内容都列好了，但要**全部导入**。

---

## 关于 20000 字上限

平台限制是**单条规则** ≤ **20000 字**，总数 ≤ **130 条**。这是**单条**上限，不是总量上限。

分层小人通常只有 4 条规则（HTML + 样式 + 脚本，图片内嵌再拆几段）。如果图片很大，工具会自动把 base64 切成不超过 18000 字的段、分散到多条规则里，靠占位符在运行时拼回完整图片。

**什么时候用图床 URL 更好**：多张卡共用一套素材，或想让卡片文件小一点。素材卡片上填了 `https://` 地址就优先用它。

---

## 其他硬约束

1. 外链素材必须 `https://` 且域名在平台白名单里
2. 代码里不能自己写 `data-*`（会被净化删掉），工具已全部避开
3. 层级保持 1000–1999
4. 匹配式在全文里必须**唯一**：只放 `statusbar`
5. 公开审核的「固定传输字符 2000–15000」只算**人设和常驻世界书，不含正则包**

排查问题：聊天页 URL 加 `?sdkDebug=1` 打开调试面板。

## 生成的代码长什么样

- 一层 `position:fixed` 的 `div` 管位置，里面依次是摇摆 / 浮动 / 跟随 / 倾斜 / 呼吸五层
- 分层模式下最里面是「舞台 + 若干图层」，每层用 `background-position` 取图的一块
- 普通模式下是若干 `<img>`，用 class 切换
- 一段 `<style>` 和一段 **ES5** `<script>`

脚本对 `sdk` 做能力探测：MMD 里走平台 `sdk`，普通网页里降级到 `localStorage`，所以这段代码贴到普通 HTML 页面也能跑。

## 在手机上用

窄屏（宽度 ≤ 900px）会自动从三栏变成**单栏 + 底部切换**：

```
[ 素材 / 编辑 ]   [ 预览 ]   [ 参数 ]
```

一次只显示一栏，点底部按钮切换，打开时默认停在「预览」。顶部按钮自动改成两列，控件也放大了（手指比鼠标粗）。

**但要说清楚**：手机适合**调参数、看预览、拖一拖试手感**；框选分层区域、涂手动修饰画笔这类精细活，还是电脑上舒服得多。

另外，**导出的产物本身是触摸兼容的**——拖拽和点击走的是 pointer events，不是鼠标事件。

## 已知限制

- 纯前端无 AI，**"上传照片生成 3D 模型"做不到**。分层小人给你的是「你的立绘 + 视差动效」，不是真 3D
- 分层视差是**固定方向的偏移**，不是真三维旋转；位移调太大会看出图层分离
- 捏小人是简笔画层次，别期待精致度
- 预览是 iframe 模拟环境，挂载点和 `sdk` 存储的差异要回聊天页确认
- 鼠标跟随靠 `pointermove`，触屏没有光标，不会触发
- 小人覆盖那块区域（默认 150px 宽）是**滚动死区**（`touch-action:none`）
- 抠背景适合**纯色或近似纯色背景**
- 实测环境是 Edge（Chromium），Firefox / Safari 未实测

## 这个版本验证过什么

**分层导出**（`_work/test-layer.mjs`，15/15 通过）
- 注入分层数据后检查产物结构、每层的 `background-position`、尺寸换算
- **立绘数据在 CSS 里只出现 1 次**（`inherit` 生效，切块不涨体积）
- 模拟平台替换后结构完整；官方校验器 **0 error**
- 用像素合成了 `视差示意.png`，确认「头动得多、身体动得少」的方向正确

**产物合规 + 分段还原**（`_work/verify-export.mjs`）
- 模拟平台替换顺序拼回 HTML，再解码每张内嵌图的 base64、**检查图片魔数**
- 官方校验器：多规则包与单条包都是 **0 error**

**抠图 + 提色 + 画笔**（`_work/test-cutout.mjs`，27/27 通过）
- node 里模拟 Image/canvas 直接跑工具的函数，含**连通性**验证（被角色包围的同色区域不误删）
- 提色用合成的「上蓝发/中肤色/下红衣」图验证三个颜色都取对
- **画笔**：擦除让像素变透明、恢复从原图取回、笔刷范围外不受影响、连笔中间不跳点

**运行时行为**（`_work/test-generated-runtime.mjs`，16/16 通过）
- 挂载、素材切换、点击不重复触发、拖拽 + 边缘吸附、位置写入存储、换会话重挂载后仍有效、窗口变化救援、`persist: none` 不写存储

**界面冒烟**（`_work/test-tool-ui.mjs`，19/19 通过）

**小人视觉**（`_work/render-dolls.mjs`）
- 沙盒里跑不了浏览器，所以写了个极简 SVG 光栅化器把零件渲染成 PNG 反复检查（`零件-*.png` 就是它出的）
- 光栅化器本身先用已知图形（圆/矩形/透明）自测过

未验证：真实 MMD 聊天页里的表现（需要平台账号与实例）；分层小人在真实立绘上的观感（需要你拿自己的图试）。

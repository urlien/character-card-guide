草稿与恢复

自动保存只在当前设备、当前浏览器中有效。移动文件、换浏览器或清理数据后可能读不到草稿，请经常下载配置。

键盘：Ctrl/Cmd + S 下载配置；在非文本框中 Ctrl/Cmd + Z 撤销，Shift + Z 重做。文本框里保留原生撤销。

安装时携带原卡文字

平台正则 JSON 必须包含这些字段，不能用 null。默认空字符串是否会覆盖原卡，在真实平台上尚未验证。给已有卡安装前，请备份并把原文字填到这里；也可导入后在平台逐项恢复。

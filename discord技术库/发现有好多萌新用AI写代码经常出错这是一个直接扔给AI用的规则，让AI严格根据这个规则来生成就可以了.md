一、功能栏是什么

一句话： 功能栏是一个“全局开关”，放在里面的代码会对所有对话生效。

```
用户人设（局部）：只有当前角色卡能看到
功能栏（全局）：你所有角色卡都能看到
```

什么时候用功能栏？

· 美化面板的CSS样式（放在功能栏，所有卡都能美化）
· 全局侧边栏按钮（放在功能栏，所有卡都能用）

什么时候用用户人设？

· 状态栏框架代码（每个卡的状态栏字段不一样，放用户人设）
· 状态栏CSS样式（放用户人设，因为不同卡配色不同）

操作： 找到MMD的“功能栏”输入框，把正则替换粘贴进去就行。

---

二、正则替换是什么

一句话： 正则替换 = 自动查找并替换文字。

```
AI输出：你吃了【某个东西】吗？
正则：查找【某个东西】，替换成“饭”
结果：你吃了饭吗？
```

侧边栏/状态栏就是靠这个实现的：

```
AI输出：【美化】两个字
正则：查找到【美化】，替换成一整段HTML代码
结果：页面上出现了一个漂亮的美化面板
```

怎么配：

1. 在MMD找到“正则替换”设置
2. 点“添加”
3. 在“查找”框里填：【美化】
4. 在“替换为”框里粘贴我给你的一大段代码
5. 保存

AI只要回复里出现【美化】三个字，就会自动变成面板。

---

三、侧边栏代码怎么用

不需要懂代码，只需要复制粘贴：

步骤1： 在功能栏添加一条正则

· 查找：【美化】
· 替换为：（粘贴ai给你的美化代码）

步骤2： 在AI的回复里，让AI在末尾加上【美化】

步骤3： 发出去后，页面右侧就会出现美化按钮。

原理：

```
你发的消息 → AI回复 → 回复里包含【美化】 → 正则自动替换成代码 → 页面出现按钮
```

四、我给你的所有东西怎么放

功能 放哪里 触发词 干什么用
状态栏框架 用户人设正则 <UI_UI> AI输出状态数据时自动生成卡片
状态栏CSS 用户人设正则 <CSS> 给卡片加上配色样式
隐藏键值对 用户人设正则 [xxx=xxx]格式 把AI输出的数据藏起来
美化面板 功能栏正则 【美化】 切换全局配色主题
召唤器/侧边栏 功能栏正则 【召唤器】或【侧边栏】 游玩指令面板
人设创建面板 用户人设正则 【创建身份】等 创建角色用的表单
公告面板 功能栏正则 【公告】 显示更新公告

五、别人最常问的问题

Q：为什么我复制代码进去没反应？
A：检查三个东西：

1. 正则的“查找”和“替换为”有没有填对（一个字都不能错）
2. AI的回复里有没有出现对应的触发词
3. 代码有没有被截断（MMD输入框有字数限制，超长需要分段）

Q：代码太长放不下怎么办？
A：告诉ai，ai帮你拆成两段。比如【身份收尾】和【身份收尾二】，两段拼接。

Q：为什么点按钮没反应？
A：可能代码里的JS被截断了。把完整代码发给ai，ai可以你压缩
AI就会自动在每

六、最重要的提醒

1. 代码不能换行：onerror="..."里面的JS代码必须写成一行，否则MMD会截断
2. 正则顺序很重要：状态栏的三段正则必须按顺序放（先放隐藏键值对，再放框架）
3. 触发词必须一模一样：代码里写的查找【美化】，AI输出也必须是【美化】，多一个空格都不行
4. 功能栏≠用户人设：全局样式放功能栏，当前卡专属放用户人设

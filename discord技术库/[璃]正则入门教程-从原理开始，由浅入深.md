**五、替换框里的特殊写法（当前 魅魔酒馆）**
> 除了普通 HTML，替换框还认这些：
写法                    作用                  注意
`$1` `$2`              填回捕获组              通用
`$hp` `$mood`           填回 KV 字段           仅当第一个捕获里同时有 :: 和 ;;
`(random(长剑|战斧|法杖))`  每次随机显示其中一个     多个 random 各自独立掷骰
`{{random:A::B::C}}`      同上，官方文字变量形态   两种写法并存
`{{user}} {{char}}`       玩家名 / 角色名        只在开场白生效，AI 回复里不会换
替换留空                 隐藏匹配内容           模型侧原文还在

> 随机的一个好玩用法：捕获组可以当随机选项。
查找：  `/我选择(.+)/`
替换：  你选了 `$1`，真是个 (random(不错的|绝妙的|有待商榷的|`$1` 自己的)) 选择。
> 玩家说「我选择苹果」，可能看到「真是个绝妙的选择」，也可能看到「真是个苹果自己的选择」。

**六、一条正则在平台里怎么跑（避免默默失效）**
> 顺序很重要：
AI 吐出带标记的原文
平台从上到下依次跑全部正则
每一条看到的，是已经被前面的正则改过的文本
替换出来的 HTML 还要再过一遍 markdown（`*害羞*` 这种星号会被吃成斜体）

> 因此有三条实战纪律：

1. 用固定标记，不要匹配散文。
`<status>`、`<css>`、`<ztl>` 这种暗号最稳。

2. 后面的正则不要在替换内容里写出前面的标记原文。
比如悬浮球的代码注释里写了 `<status>`，状态栏那条正则会把这段代码也当成数据块吃掉，悬浮球会静默消失、还不报错。需要提到别的标记时，在 JS 里拆开拼接：`'<sta'+'tus>'`。

3. 交互 HTML 的两个结构红线。

最外层容器加 `onclick="event.stopPropagation()"`，否则点击会冒泡到气泡，触发编辑/复制。
所有 `id` 必须带时间戳，例如 `BOX_1729584719271`。聊天记录全在同一页，重复 id 会让「第二次使用就失效」。

**七、手填时怎么写，导入时怎么写**

手填： 打开 MMD 正则界面，名称随便起，查找框贴 `/.../`，替换框贴要换成的内容。
批量导入： 当前 MMD 的 json 必须恰好这四个顶层键：
```json
{
  "pageDepth": 2,
  "statusbar": "",
  "beginning": "",
  "regex_scripts": [
    {
      "id": -1,
      "scriptName": "规则名",
      "findRegex": "/<status>/",
      "replaceString": "<div>这里是替换后的HTML</div>"
    }
  ]
}
```
json 里的坑只有两个：

> 替换内容里的真实换行要写成 `\n`，不能在 json 字符串里直接按回车
> 替换内容里的双引号要写成 `\"`，或 HTML 改用单引号
> 不要手搓转义，用脚本 `json.dumps` 生成最稳。
> 最好使用skill，自带审核脚本

**八、30 秒自测**

看到下面这句 AI 原文：
`好感度：42`

你想让玩家看到：
`❤ 好感 42`

查找和替换该怎么写？
答案：
||查找：  `/好感度：(\d+)/`
替换：  `❤ 好感 $1`||

> ||如果写成 /好感度：\d+/ 而没有括号，$1 是空的，因为你没「抓住」那串数字。||


**九、入门够用的符号表**
符号        记住这一句就行
`/.../`     查找必须戴这副眼镜
`.`        任意一个字
`\d`       一个数字
`\s`       一个空白
`+`        前面那个东西，至少一个
`*`        前面那个东西，可以没有
`?`        写在 + * 后面时：别贪心，尽早停
`[]`       这里只能是列出的字
`[^]`      这里不能是列出的字
`()`       抓住，留给 $1
`$1`       第一个括号抓到的原文
`|`        或者（在 [] 外面才是或者）
`\`        取消后面符号的魔法
`g`        全部换，不只换第一次
`s`        让 . 能跨行

> 先会这 14 个，MMD 里 90% 的正则都能看懂、能改。状态栏引擎、雷达法那些是「替换框里塞了一大段 HTML/JS」，查找本身往往只是 `/<ztl>/` 这么短。

**𝓨𝓞𝓕𝓮𝓷𝓰** (2026-09-06 12:28:20):
> ***才发现藏经阁里正则相关的没有简单的入门说明，所以写一份***

正则看起来像天书，在 MMD 里其实只干一件事：
在 AI 的回复里找一段文字，把它换成另一段文字。

像 Word 的「查找并替换」，但查找条件可以是「某种形状」，而不只是某个固定词。
AI 每说完一句话，平台会按顺序跑你写的全部正则。命中了就换，没命中就原样显示。玩家看到的气泡，已经是替换后的结果。


**一、一条正则长什么样**
每条正则只有两个核心：
查找（findRegex）去找什么          -> `/好感度：(\d+)/`
替换（replaceString）找到后换成什么 -> `❤ $1`

当前 MMD 导入时，一条规则长这样：
```json
{
  "id": -1,
  "scriptName": "把好感度变成爱心",
  "findRegex": "/好感度：(\\d+)/",
  "replaceString": "❤ $1"
}
```
记住四个死规定：

查找必须写成 /内容/标志，两边有斜杠。写成 好感度：(\d+) 这种裸写法，测试框可能显示通过，聊天里却不替换。
固定标记也要包斜杠：写成 /<status>/，不要写成 <status>。
最多 130 条；查找 ≤1000 字；替换 ≤20000 字。
> 正则只改显示，不改发给 AI 的原文。隐藏一段文字，玩家看不见，模型下一轮仍能读到。

**二、先把「查找」学会：从固定词到形状**
1. 最简单：找固定词

查找：  `/苹果/`
替换：  `红苹果`

AI 写「桌上有一个苹果」，玩家看到「桌上有一个红苹果」。
斜杠中间就是要找的字。现在它还不会「模糊」，只认一模一样的「苹果」。

2. 点 `.`：任意一个字
`.` 表示「这里随便一个字」。
查找：  `/小./`

能对上「小猫」「小狗」「小王」，对不上「小」（后面还得有一个字）。
想匹配真正的句号，要写成 `\.`。反斜杠的意思是：后面这个符号当普通字，不当魔法。

3. 加号 `+` 和星号 `*`：重复
`啊+` = 至少 1 个啊 = 啊、啊啊、啊啊啊
`啊*` = 0 个或多个啊 = （空）、啊、啊啊
`啊?` = 0 个或 1 个啊    = （空）或 啊

最常用的是 `+`：
查找：  `/哈+/`
「哈」「哈哈」「哈哈哈哈」都能对上。

4. 方括号 []：这里只能是列出的这几个
查找：  `/[abc]/`
只对「a」或「b」或「c」中的一个字。
中文同样能用：
查找：  `/[男女]/`
对「男」或「女」。

常见速记（本质都是方括号的简称）：
`\d` 一个数字，等于 [0-9]
`\s` 一个空白（空格、换行、制表）
`\w` 字母、数字、下划线（对中文不太好用，中文场景少用它）

> 所以「一串数字」写成 `\d+`。

5. 圆括号 ()：先抓住，再拿去用
这是正则里最值钱的功能。

圆括号做两件事：
把这一段单独抓出来
替换时用 `$1`、`$2` 把抓到的内容填回去

查找：  `/好感度：(\d+)/`
替换：  `❤ $1`

AI 原文:`好感度：75`    `好感度：3`
玩家看到: `❤ 75`       `❤ 3`

(\d+) 抓住的那串数字，就是 $1。
两个括号就有 $1 和 $2，按左括号出现的顺序编号：

查找：  `/HP:(\d+)\/(\d+)/`
替换：  `生命 $1 / $2`
AI 写 `HP:80/100`，玩家看到 `生命 80 / 100`。
> 注意：模式里如果要写斜杠 /，必须写成 `\/`，否则平台会以为查找式提前结束了。HP:80/100 中间那条杠，查找里就要写成 `\/`。


6. 问号让「贪心」变成「刚好够」
默认的 `.*` 或 `.+` 会尽量吃得多，容易把两段内容一次全吞掉。
AI原文：  `<status>血量80</status>` 中间还有字 `<status>心情好</status>`
查找：    `/<status>.*<\/status>/`
`.*` 会从第一个 `<status>` 一路吃到最后一个 `</status>`，中间那段字也会被吃掉。这叫贪心。
写成 `.*?` 就变成「碰到第一个结束标记就停」：
查找：`/<status>.*?<\/status>/`

状态栏、隐藏块几乎总是用这个。跨多行时再加 `s` 标志，让 `.` 也能匹配换行：
查找：  `/<status>([\s\S]*?)<\/status>/s`
[\s\S] 的意思是「空白或非空白」= 任意字符，含换行。这是跨行匹配的稳妥写法。

7. 标志写在最后那条斜杠后面
/内容/标志
标志  |作用              |什么时候用
`g`     |全部替换，不只第一次    |一条消息里可能出现多次时
`i`     |英文大小写不敏感    |    匹配 HP 和 hp
`s`     |让 . 能匹配换行        |匹配跨行的标签块
> 当前 MMD 里，固定标记如 `/<status>/` 一般不用 `g` 也行；一条消息里会重复出现的内容（关键词高亮、多次 `[键=值]`）要加 `g`。

**三、魅魔酒馆 里正则真正在干什么**
角色卡作者几乎不用正则去「改句子」，而是用它做三件事：

用途 1：把隐藏数据变成好看的面板
你让 AI 每轮在正文末尾输出固定格式：

> 莉娅轻轻点了点头。
> `<status>hp::80;;mood::害羞;;favor::72</status>`

一条正则把 `<status>…</status>` 整段吃掉，换成 HTML 状态栏。玩家只看到漂亮面板，看不到那些 `hp::80`。

当前 魅魔酒馆 对这种「字段名::值;;字段名::值」格式有原生支持：查找的第一个括号里同时有 :: 和 ;; 时，替换里可以直接写 $hp、$mood、$favor。
查找：  `/<status>(.*?)<\/status>/`
替换：  `<div>❤ $favor　HP $hp　心情 $mood</div>`
> 这就是说的原生 $field，固定字段、零 JavaScript，最轻的写法。

用途 2：藏起不该给玩家看的字
查找：  `/<UpdateVariable>[\s\S]*?<\/UpdateVariable>/s`
替换：  （留空）
> 替换框什么都不填，匹配到的内容就从气泡里消失。适合变量更新块、作者备注、给模型看的内部指令。

用途 3：给某些词套上颜色/样式
查找：  `/（(.+?)）/g`
替换：  `<span style="color:#ff6d97">（$1）</span>`
> 所有中文括号里的旁白，显示成粉色。`$1` 是括号里的原文，原样放回去，只是外面多了层样式。

**四、四个能直接用的完整例子**
例子 A：把「【开心】」变成emoji
AI 习惯在句首写情绪标签。
查找：  `/【(开心|难过|生气|害羞)】/`
替换：  `$1`

更进一步，按情绪换不同符号，要写多条，或接受统一样式。入门先做统一的：
查找：  `/【开心】/`
替换：  😊
查找： `/【难过】/`
替换：  😢
> 一条正则干一件事，最好懂，也最好改。

例子 B：隐藏内部标签，只留正文
约定 AI 这样输出：
她把茶杯推到你面前。
`<note>本轮好感+2，地点仍在茶室</note>`

名称：     隐藏note块
查找：     `/<note>[\s\S]*?<\/note>/s`
替换：     （空）
> 玩家只看到「她把茶杯推到你面前。」而看不到被替换为空的信息，但是AI可以正常看见。

例子 C：把 `[金币=120]` 藏起来留给后面的脚本用
> 雷达法、悬浮球常用这种「数据信标」：

查找：  `/\[([^=\]]+)=([^\]]+)\]\s*/g`
替换：  `<span style="display:none">[$1=$2]</span>`

人话拆开：

`\[` `\]`：匹配真正的方括号（方括号本身是正则魔法，要加反斜杠）
`([^=\]]+)`：键名，不能含 = 或 ]
`=`：中间那个等号
`([^\]]+)`：值，到 ] 为止
`\s*`：后面若有空格/换行一并吃掉，避免留下空白行
`g`：一条消息里多个 [键=值] 全部处理
> 替换后页面上看不见，但 HTML 里还在，JS 可以扫到。

例子 D：固定标记触发一整块 HTML
> 这是状态栏、美化最常用的套路：不要去匹配千变万化的正文，只匹配一个永远不变的标记。

查找：  `/<css>/`
替换：  `<style>.z-box{padding:8px;border-radius:8px;background:#282A2E}</style>`

第一句话或状态栏字段里放一个 `<css>`，这条正则命中后，整页样式就注入了。

> 为什么用固定标记，不用「匹配任意一段描写」？
> 因为正文每轮都在变。匹配「形状」很容易哪天误伤一句普通对话。标记是你自己规定的暗号，只有 AI 按协议输出时才会出现。

【任务】帮我做一张"同层全屏"角色卡。
同层＝一个全屏层，所有界面（开屏/捏人/状态页…）都装在层里，靠 class 切换；层默认隐藏，点左上角"眼睛"开关。
【输出格式】每件东西输出为一条"正则规则"：查找＝我给你的标记，替换＝一整段完整代码（HTML+CSS+脚本混写）。
代码必须完整、可直接复制，不许省略、不许"以下同理"；太长就拆成多条，一条一功能。
【硬规矩】
1. 类名统一前缀；只用 div/span 等普通标签；不用 data-*；不用 $ 变量名。
2. 每个脚本：IIFE＋防重标记；找元素必须轮询等待；事件用 document 委托。
3. 全屏层默认 display:none，加"打开类"才显示；层要搬到 body 底部。
4. 读消息：整页文字兜底；多对话时只读"正在显示的那段"。
5. 进度状态只认"AI 正文里的文本块"（如 [状态]…[/状态]），不许拿 localStorage 当存档。
6. 发消息：SDK 优先 → 原生输入框兜底 → 失败必须提示。
7. 施工顺序：外壳 → 捏人 → 一个数据页 →（我确认后再继续）。
   每步给出验收标准；我测过说"过了"，你才做下一步。

**黑白琴键（奥特曼参赛卡：残光）四组** (2026-09-23 12:25:23):
// 骨架（类名按你自己卡改）
var lastKey = null;
function tick(){
  var root = document.getElementById('layer'); if(!root) return;      // ① 等层就绪
  var t = activeText();                     // 自备：只读"当前显示对话"的文字
  var arc = /【玩家档案】([\s\S]*?)【\/玩家档案】/.exec(t);
  var key = arc ? ('A:' + arc[1].replace(/\s+/g,'').slice(0,48)) : ''; // ③ 对话指纹
  if(key !== lastKey){                                               // 换对话了
    lastKey = key;
    resetLayer();                                                    // 清层里状态
    land(key ? 'main' : 'splash');                                   // ② 定落点
  }
}
setInterval(tick, 1500);

**燚（被秋姐变性版）** (2026-09-16 12:13:49):
主要功能
• 三栏式插画工作台
• 新增、复制、删除、排序和搜索图片预设。
• 可选择本地图片进行构图预览。
• 可填写 HTTPS 图片直链，用于正式 MMD 导出。
• 自定义多个触发关键词。
• 支持三种插入位置：
• 命中句之后
• 命中段落之后
• 关键词之后
• 支持每条回复触发一次或每处都触发。
• 支持英文大小写、完整单词匹配。
• 可调图片画幅、裁切方式、水平与垂直焦点。
• 可设置图注、替代文字、圆角、宽度和画框风格。
• 在编辑器内输入剧情即可实时查看插图位置。
• 支持批量建立图片预设。
• 自动保存编辑进度，并支持项目备份、恢复。
• 可以导入并合并现有的 MMD 四键正则 JSON。

两种触发方式

正文关键词

模型正常写剧情，正文出现预设关键词后自动插图。

导出时使用安全的两段正则链：

剧情关键词 → 唯一内部标记 → 图片 HTML

这样可以避免其他图片规则继续匹配已经生成的图片 HTML。

语义标记

由模型根据剧情语义输出：

【剧情插图:rain_window】

随后正则将其替换为预设图片。编辑器也会自动生成可复制到人设或世界书里的模型规则。

使用步骤

1. 打开编辑器。
2. 进入“图库”，新建或选择一张插画。
3. 在“设置”中填写关键词和图片地址。
4. 回到“剧情”，输入测试文字并检查实时效果。
5. 点击右上角 导出 MMD JSON。
6. 将下载的 JSON 导入当前 MMD 旧版聊天页。

本地上传的图片只用于编辑器预览。正式导入 MMD 时，每张启用的图片都需要填写可公开访问的 HTTPS 图片直链。

已完成 JavaScript 语法检查，以及当前 MMD 导出格式校验：0 错误、0 警告；320px、412px 手机宽度和桌面布局均无横向溢出。

## 一、状态栏的"三件套"结构（必须理解）

状态栏由三部分绑定组成，改任何一个，另外两个大概率要一起改：

1. **状态栏文本** — 位于角色卡「第一句话」末尾
   格式：固定标记开头 + 一行一个字段的键值对 + 固定标记结尾
   ```
   【烛骑士档案】
   对话轮次：0
   干员：薇薇安娜
   好感度：5.5
   动作描述：……
   内心独白：……
   时间：3月12日 17:30
   地点：罗德岛办公区-人事部
   【档案终】
   ```
   AI 每轮回复末尾按这个格式输出纯文本。

2. **匹配正则** — 在「设置正则」弹窗的「匹配正则 (Pattern)」框
   作用：从 AI 输出中按字段捕获数据。捕获组顺序 = 文本字段顺序。

3. **替换内容（代码）** — 同一弹窗的「替换内容」编辑器（Monaco）
   作用：HTML/CSS/JS 可视化面板，用 `$1` `$2` ... `$N` 占位符接收正则捕获组，渲染成漂亮的状态栏。

> **联动规则**：文本加/删/改字段 → 正则捕获组跟着变 → 代码 `$N` 占位符重新对应。
> 任何一环不同步的结果：正则匹配不上（只显示文本、不出面板）或占位符错位（数值乱显示）。

## 二、正则写法（最关键的坑）

### 坑 1：正则输入框是「单行 input」，换行会被吃掉

- 编辑页的「匹配正则」是一个 **单行 input**，粘贴带 `\n` 换行的正则，换行会丢失！
- 之前失败的写法（字段间用空格或换行分隔）：
  ```
  /【烛骑士档案】\n对话轮次：(.*?)\n干员：(.*?)…/s   ← 换行被吃掉后变成
  /【烛骑士档案】对话轮次：(.*?)干员：(.*?)…/s        ← 字段名直接粘连，但文本里中间有换行 → 匹配失败
  ```

### 正确写法：字段间不用任何分隔符，靠 `(.*?)` + `/s` 跨行吞噬

```
/【烛骑士档案】\s*对话轮次：(.*?)干员：(.*?)衣着：(.*?)衣柜：(.*?)唇部：(.*?)口腔：(.*?)乳尖：(.*?)阴蒂：(.*?)小腹：(.*?)穴口：(.*?)双足：(.*?)肛门：(.*?)敏感区域：(.*?)当前计划：(.*?)好感度：(\d+(?:\.\d+)?)\s*动作描述：(.*?)内心独白：(.*?)时间：(.*?)地点：(.*?)【档案终】/s
```

关键点：
- 开头 `【烛骑士档案】` 后面跟 `\s*`（因为文本里是换行）
- 此后每个字段名直接接 `(.*?)`，**不加任何分隔符** —— `/s` 模式下 `(.*?)` 会跨行吞掉换行直到遇到下一个字段名
- 结尾 `【档案终】` 直接闭合

### 坑 2：数值字段必须用「数字捕获」，不能 `(.*?)`

如果 `好感度：(.*?)`，捕获到的值是 `5.5\n`（**带换行**），替换时拼进 CSS：
```html
<div class="viv-bar-f" style="width:5.5
%;"></div>
```
→ 无效 CSS 值 → 浏览器忽略 → **进度条满格**！

正确：
```
好感度：(\d+(?:\.\d+)?)\s*动作描述：
```
纯数字捕获（支持小数），后面 `\s*` 吃掉换行。

## 三、替换内容代码要点

- 字数限制 **20000**，实测 8-9K 字符正常
- 占位符 `$15` 对应第 15 个捕获组（正则从左到右数）
- 风格：中世纪信纸 = 羊皮纸渐变底 + 火烧焦边（radial-gradient 叠加）+ 火漆印章（CSS 圆形）+
  Cinzel 哥特字体 + 堆叠页数感（box-shadow 多层错位：2px/4px/6px/8px 逐层加深）
- 头像/可切换表情盒：用 `<img>` 绝对定位 + onclick 切换数组，`event.stopPropagation()` 防止点击冒泡

### 占位符映射必须校验

写完后用脚本检查 `$1`~`$N` 是否全部出现、无多余：
```python
import re
code = open('3-替换内容.txt', encoding='utf-8').read()
used = sorted(set(int(x) for x in re.findall(r'\$(\d+)', code)))
print('占位符:', used)
print('缺失:', [i for i in range(1, N+1) if i not in used])
```

## 四、如何在编辑页安全更新代码（Monaco 编辑器）

⚠️ 替换内容编辑器是 **Monaco**，普通 JS 赋值/键盘事件不生效，会越搞越乱（实测内容翻倍叠加）。

**可靠方法：系统剪贴板 + CDP 原生键事件**

1. **清空**：先点击编辑器聚焦，然后用 CDP 发真实键事件：
   - `Ctrl+A` 全选 → `Ctrl+X` 剪切（Monaco 认得 CDP 的 rawKeyDown）
   - 此时编辑区变空，剪贴板里是被剪切的内容
2. **写入新内容到系统剪贴板**（PowerShell，注意中文路径要用英文临时文件）：
   ```powershell
   $t = [System.IO.File]::ReadAllText('C:\Temp_code_full.txt', [System.Text.Encoding]::UTF8)
   Set-Clipboard -Value $t
   ```
3. **粘贴**：Ctrl+V（CDP rawKeyDown + keyUp）
4. **验证**：弹窗「字数」统计应等于新代码字符数；点「保存配置」

> 不要用 navigator.clipboard.writeText（页面非用户手势会被拒）；
> 不要在 Monaco 里用 type_text 长文本（会叠加不是替换）。

## 五、测试流程（成功判定）

1. 编辑页点「保存编辑」（URL 会变成 `?id=xxx&r=2` → 保存成功）
2. 右侧「对话测试」tab → iframe 聊天窗口
3. **右上角刷新按钮**（`ico_refresh2_dark.png` 图标）点一下重置对话
4. AI 首条回复若输出状态栏文本且**渲染成面板**（有 CSS 样式、图片、进度条）→ 成功
5. 只显示纯文本/数字 → 失败，检查「正则匹配」或「占位符映射」

> 注意：对话测试发消息会消耗电量，验证时尽量用刷新按钮而非发消息。

## 七、易错清单

| 问题 | 原因 | 修复 |
|------|------|------|
| 只显示文本不出面板 | 正则没匹配上（换行被吃/字段粘连） | 用 `\s*`+字段直连写法 |
| 进度条满格 | 数值带 `\n` 拼进 CSS | 正则用 `\d+` 数字捕获 |
| 面板内容重复叠加 | Monaco 里多次 insertText | Ctrl+A+Ctrl+X 清空后粘贴 |
| 占位符错位 | 字段顺序/捕获组/`$N` 不同步 | 脚本校验 |
| 粘贴不生效 | navigator.clipboard 被拒 | PowerShell Set-Clipboard + CDP Ctrl+V |

## 八、角色卡制作通用流程（衔接）

1. 收集资料：PRTS wiki + 萌娘百科（台词必须官方来源）
2. 整理人设：`<基本资料>` `<外貌特征>` `<服装与装备>` `<性格>` 结构
3. 撰写人设：公开卡 2000-5000 字，人设+世界书 token ≤ 15000
4. 开场白/第一句话：剧情引导 + 状态栏模板（末尾）
5. 配置世界书：25-30 条目，`[世界观]` `[角色]` `[设定]` `[剧情]` 分类
6. 设置状态栏：文本 + 正则 + 替换内容三件套（本指南）
7. 测试发布：对话测试 → 保存 → 公开（每日次数有限）

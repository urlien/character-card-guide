## 📌 这是什么

`character-card-guide/明日方舟剧情/` 存放明日方舟全量剧情原文（原始指令脚本格式），按活动/主线/干员密录分目录组织。共 **2965 个章节文件**（截至 2026-11-02）。

## 🗂 目录结构

```
明日方舟剧情/
├── <活动名>/              ← 77 个活动，每个活动一个文件夹
│   ├── <章节名><关卡号> <类型>.txt  例：收信地：终点TO-1 行动前.txt
│   └── ...（每个章节独立文件）
├── 主线剧情/
│   ├── 第00章 ~ 第17章/   ← 主线按章分（含教程关TR、幕间ST、特殊关SPST）
│   └── 其他/              ← 区域进入提示、章节回顾等无 storyId 的文本
├── 干员密录/
│   └── <干员中文名>/      ← 332 个干员
└── 其他剧情/
    ├── 肉鸽事件/          ← obt/rogue 月度对话、结局书
    ├── 肉鸽/              ← obt/roguelike 集成战略
    ├── 生息演算/          ← obt/sandboxperm + sandbox_1
    ├── 档案/              ← obt/record 章节笔记
    ├── 愚人节活动/        ← act3fun~act7fun
    ├── 特殊活动/          ← 刻俄柏的梦、大帝说唱、PRTS文献等
    └── 游戏引导/
```

## 📏 命名规则

- 文件名 = `章节名 + storyCode + 空格 + avgTag`，如 `一封想写的信TO-ST-1 幕间.txt`
- 半角冒号 `:` 转为 `_`（Windows 兼容），如 `6:44P.M.` → `6_44P.M.`
- 全角标点（`：` `！` `，`）保留

## 📃 操作流程（下次出新活动时）

### 第 0 步：读本文件，进入工作目录

```bash
# 判断当前情况：仓库是否已 clone 到本地
ls D:\Hermes\暂存文件\ak-rebuild\repo 2>/dev/null || echo "需要重新 clone"
```

### 第 1 步：拉最新索引，对比缺什么

```python
# 用 r2 拉最新 story_review_table.json
# 用 git trees API 拉 ArknightsStoryJson 完整目录树（真实全量基准）
# 对比：数据源全量 vs 仓库已有文件 → 得到缺失清单 download_missing.txt
```

**关键：** 完整性基准是 **ArknightsStoryJson 的 zh_CN/gamedata/story/ 全树**（当前 2001 个）。不能只信 story_review_table——它不收录隐藏关/肉鸽。对比时注意：
- 树路径带 `zh_CN/gamedata/story/` 前缀（无前导斜杠），转成相对路径 `.json` → `.txt`
- 只统计 `zh_CN/`（仓库树含 en_US/ja_JP 等多语言，全语言合计 9519 个，别混淆）

### 第 2 步：下载缺失文件

```bash
# 生成 aria2c 输入（URL + out=raw/<相对路径>）
aria2c -i aria_missing.txt --dir=D:\Hermes\暂存文件\ak-rebuild \
  --all-proxy="http://127.0.0.1:7897" \
  --max-concurrent-downloads=12 --max-connection-per-server=2 --split=2 \
  --timeout=30 --retry-wait=3 --max-tries=8 --console-log-level=warn
```

### 第 3 步：归类生成

- 活动：`raw/activities/<actXX>/...` → `out/<活动名>/<章节名+storyCode+avgTag>.txt`
- 主线：`obt/main/level_main_XX-` 或 `level_st_XX-` 或 `level_spst_XX-` → `out/主线剧情/第XX章/`
- 教程 TR：`level_main_tr` → `out/主线剧情/第00章/`
- 密录：`obt/memory/story_<干员id>_N_M` → `out/干员密录/<干员中文名>/`（干员名从 character_table.json 的 `char_*_<id>` 匹配）
- 引导：`obt/guide/` → `out/其他剧情/游戏引导/`
- 肉鸽：`obt/Roguelike/` → `out/其他剧情/肉鸽/`
- 隐藏关：`activities/.../level_*_hidden_stXX` → `out/<活动名>/隐藏关/`（storyName 从同路径 JSON 取，如 逃离/选择/路漫漫）

### 第 4 步：质量校验

- 文件总数 == 数据源全量树数
- 无空文件（<50B）
- 无 Windows 非法字符文件名（`<>:"|?*`）——半角冒号已转 `_`
- 抽查正文开头是 `[HEADER(...)]`

### 第 5 步：同步到仓库 + 推送

```bash
# 拷贝 out/ → repo/明日方舟剧情/
# git add -A && git commit -m "..." && git push <token-url> main
```

⚠️ 推送必须用 token URL：`https://<TOKEN>@github.com/urlien/character-card-guide.git`（token 由用户在开始前提供，用完即失效）
⚠️ **只准改 `明日方舟剧情/`，其他目录一律不动**（角色卡制作指南/黍/discord技术库 等）
⚠️ 删除旧文件前先把清单给用户过目
